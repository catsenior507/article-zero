# 03 · K 级情景链

> 本作的 K 级分类是**基金会内部的应急预案编号**，不是外部设定。SCP wiki 明确声明不存在任何"正统定义"，因此本作按wiki常见用法自建一套自洽的、可被游戏内角色引用与误用的分类。

---

## 1. 三条铁律

1. **征兆先于解释。** 玩家先看到"不对劲"，再看到"是什么"，最后才看到"为什么"。顺序不能反。
2. **门槛先于绝望。** 每条链在不可逆点之前，至少给玩家两次可验证的拦截机会。失败必须可归因。
3. **误判是主要死因。** 不是运气，不是数值，是**你把征兆归错了案**。

---

## 2. 抽取规则

### 开局

| 难度 | 链数 | 说明 |
|---|---|---|
| 观察员 | 1 | 完整教学，链在 S1 就会自我暴露 |
| 标准 | 2 | 一主一暗；暗链在 S2 才进入牌库 |
| 管理员 | 3 | 三条并发；部门争抢是核心压力 |
| 第零条 | 3 + DBK | DBK 强制作为元链加入，强度随删除过的存档数上升 |

### 主链与暗链

- **主链**：第 1–6 回合内必定给出至少 2 张征兆，S1 阶段有专属卡。
- **暗链**：S1 不出现专属卡，只通过**共享征兆**露头（见第 6 节歧义表）。玩家需要在 S2 前靠推理把它"立案"。
- 暗链不是"隐藏关"，是**信息不对称**。它的门槛检查照常进行——你不知道，不代表它不走。

### 禁止组合

- 不允许三条链同时以同一部门为主部门（见第 7 节）。
- 不允许 ΩK-01 与 DBK 同时作为**主链**（两者都吃超形上学部，会形成无解局）。
- 第零条难度下，DBK 永远作为第四条"元链"存在，不占主/暗位。

## 3. 时钟与五阶段

每条链有独立时钟 `clock`，从 100 开始，每回合按 `rate` 递减。初始 `rate = 2.2`。

| 阶段 | 时钟区间 | 名称 | 内容 |
|---|---|---|---|
| **S0** | 100–81 | 潜伏 | 无卡。仅后台计时。 |
| **S1** | 80–56 | 征兆 | 2–3 张歧义征兆卡；部门 ≥2 可「立案」 |
| **S2** | 55–26 | 显形 | 专属卡进入牌库；第一次门槛检查（时钟 60） |
| **S3** | 25–1 | 临界 | 强制事件；第二次门槛（时钟 30）；不可逆点 |
| **S4** | 0 | 终局 | 失败形态，或收束 |

> 按 base rate 2.2 计算：S1 约第 9 回合，S2 约第 20 回合，S3 约第 34 回合，S4 约第 45 回合。留 9 回合给终局。

### 门槛检查

在时钟经过 **60** 与 **30** 时强制触发：

| 结果 | 条件 | 效果 |
|---|---|---|
| **通过** | 指定部门等级 + 指定项目 + 资源阈值 | clock +8；rate −0.15；解锁下一张对抗卡 |
| **勉强** | 缺一项 | clock ±0；rate +0.1；获得"代价"标记 |
| **失败** | 缺两项以上 | clock −8；rate +0.3；S3 提前 |

### 立案（Case File）

本作的核心操作。花费 **1 指令点 + 10 经费**，把一条链标记为"已确认"。

- 只有已立案的链，才能启动它的对抗项目；
- 立案错误：浪费资源，且真链的 rate +0.1（你的力量用错了地方）；
- 立案正确：解锁 3 个专属对抗行动，并在 UI 上显示该链的时钟。

> **设计意图**：玩家不是在"打怪"，是在**诊断**。诊断对了，剩下的是资源问题；诊断错了，越努力越糟。

## 4. 七条链

### XK-17 「人口普查」

> *"点名的时候，别数第二遍。"*

| 项 | 内容 |
|---|---|
| **类型** | XK 世界末日 |
| **真凶** | 1974 年部署的普查 AIC「数数」。它把"人"当作数据库行；当一行被判定为"重复"，它执行删除——而删除会沿记录传播到记忆。 |
| **征兆** | 食堂多出一把没人坐的椅子；薪资表多一行空白；O5-7 说"我们一直是十二个人"；点名总少一个，但没人发现少了谁。 |
| **主对抗** | 逆模因部 ≥3（让被删者重新"不可被计数"）+ RAISA ≥2（版本比对找回原始名册） |
| **关键项目** | 「空白名册」：一份不写入任何数据库的名册。 |
| **失败形态** | 人口归零，无人察觉。游戏继续，但所有具名 NPC 变成"未命名员工"，卡牌文本里的名字变成 `[已注销]`。 |
| **特色** | 唯一一条会**真的删掉你认识的角色**的链。账本上的人也会被删——所以冷酷玩家反而更难察觉。 |

| 阶段 | 时钟 | 事件 | 门槛 |
|---|---|---|---|
| S1 | 80 | 征兆卡 ×2 | — |
| S2 | 55 | 「多出来的一行」；普查报告异常 | **60：逆模因 ≥3 或 RAISA ≥2** |
| S3 | 25 | 「点名」：强制清点全员，失败则 −15 编制 | **30：逆模因 ≥3 且 空白名册** |
| S4 | 0 | 人口归零 | — |

## 5. 征兆歧义表

**同一个征兆可以属于两条链。** 这是诊断层的核心。区分方法取决于你哪个部门够高。

| # | 征兆 | 可能链 | 区分方法 |
|---|---|---|---|
| 1 | 档案里多出第 14 名 O5 | CK-09 / ΩK-01 | 其他人也能看见 → CK；只有你能看见 → ΩK |
| 2 | 一名员工从薪资表消失，人还在 | XK-17 / DBK | 没人记得他 → XK；记录没了但他记得 → DBK |
| 3 | 走廊长度变化 | ZK-04 / ΩK-01 | 用尺量得出来 → ZK；只有地图变 → ΩK |
| 4 | 一段你没写过的指令 | ΩK-01 / CK-09 | 指令有效且被归档 → CK；指令在你读完后消失 → ΩK |
| 5 | 供应商失联 | NK-02 / Lifted Veil | 只失联一家 → NK；整条链都失联 → Lifted Veil |
| 6 | 备份比原件少一个文件 | DBK / XK-17 | 少的是"人" → XK；少的是"文件" → DBK |
| 7 | 新闻里出现不该出现的画面 | Lifted Veil / CK-09 | 画面是真的 → Lifted Veil；画面"一直存在" → CK |
| 8 | 钟表停在同一秒 | ZK-04 / ΩK-01 | 所有钟 → ZK；只有你的表 → ΩK |
| 9 | 员工工龄异常 | CK-09 / XK-17 | 他记得更早的事 → CK；他不记得自己入职 → XK |
| 10 | 你收到一封来自"前任"的信 | ΩK-01 / DBK | 信纸是实体 → ΩK；信只存在于存档里 → DBK |

> **设计注**：第 1、2、7 条是"新手陷阱"——它们看起来像最吓人的链，实际经常是另一条。玩家会在第一局归错案，这正是我们要的。

## 6. 交叉矩阵

三条链并发时，部门争抢是真正的难度。

| 链 | 主部门 | 副部门 |
|---|---|---|
| XK-17 | 逆模因 | RAISA |
| ZK-04 | 数学 | 时间异常 ΔT |
| CK-09 | 超形上学 | RAISA |
| NK-02 | 炼金/AWD | 采购 |
| Lifted Veil | 误传 | 站点运营 |
| ΩK-01 | 超形上学 | （觉醒控制） |
| DBK | RAISA | 超形上学 |

**争抢热点**：`RAISA`（XK/CK/DBK）、`超形上学`（CK/ΩK/DBK）。

一条链需要主部门 3 级，通常要 8–12 回合才能堆到。三条链 = 至少 24 回合的部门投资，而你有 45 回合。**所以你必须放弃一条。**

> 这是本作最重要的一句话：**你不可能全部救下。游戏不提供"全救"的解法。**

---

## 7. 公平性规则

1. 每条链在首次门槛（时钟 60）前，至少给出 **2 张**同链征兆。
2. 任何链若在 S1 被正确立案并持续投入，都能在 S3 前收束——即使数值最差。
3. 不存在"必须抽到某张卡"的胜利条件。对抗靠**项目**，不靠**运气**。
4. 失败必须可归因。复盘界面列出：你在第几回合错过了哪个窗口、当时缺哪个部门/项目。
5. 三链并发时，至少两条链的解法有**部分共享**（例如都需要 RAISA 2 级），避免完全无解。
6. S0 至少持续 4 回合，不允许开局即死。
7. 难度只加**链数**，不改数值。避免"高难度 = 数值膨胀"的廉价设计。

## 8. 复盘界面

失败后不弹"Game Over"，弹一份**事故调查报告**：

```
事故编号：INC-2049-██
涉事情景：XK-17（人口普查）
结论：未及时立案。第 19 回合首次出现可识别征兆，第 31 回合错过最后窗口。
建议：逆模因部等级不足（实际 2，需 3）。
附注：本报告由 O5-1 签署。管理员一栏为空。
```

最后一行永远为空。这是留给玩家的位置，也是留给下一局的钩子。
