## 1. 判断标准

沿用 docs/21 的三条：**独占决策轴、挂得上两个以上资源、能承担一条 K 链或一个道德困境**。再加一条本作特有的：

4. **它是不是某个已存在系统的"主人"**——外务部对应外交面板，人力资源部对应资源分配，情报部对应预警。没有主人的系统，玩家点开时会觉得"这些按钮是谁在按"。

---

## 2. 三个必须补的"系统主人"

### 2.1 人力资源部（HR）

- **补的缺口**：编制 84 点、D 级 1450 人、部门士气，现在全由"系统"分配，没有部门负责；
- **机制**：每级 **编制上限 +1**、**部门士气 +1**；3 级解锁"跨部门借调"（临时补缺员，代价是另一个部门士气 −3）；
- **驻地**：Site-19（与站点运营共用，行政楼）；
- **为什么必须**：没有它，"缺员 → 士气下降"这套规则没有执行者。

### 2.2 外务部（External Affairs）

- **补的缺口**：外交面板已经能向七个政体要钱，但组织表里没有外务部；
- **机制**：每级 **拨款 +3%**、**外交冷却 −1 月**；5 级解锁"联合行动"（与盟友共管站点）；
- **驻地**：Site-12（亚洲，靠近多个政体）；
- **为什么必须**：外交是第四条收入腿（docs/20），不能挂在"采购"或"误传"下面。

### 2.3 情报部（Intelligence）

- **补的缺口**：K 级预警现在只靠末日学部，但"预警"本身是情报工作；
- **机制**：每级 **事件预览 +1 条**（提前看到下月事件的类型）、**末日学部的预警天数 +0.5/级**；
- **驻地**：Site-58（欧洲，与误传共用信号站）；
- **为什么必须**：它让"预警"变成可投资的能力，而不是单一部门的开关。

## 3. 适合事件化，不适合成树

| 部门 | 处理 | 理由 |
|---|---|---|
| 反概念部 | 事件链（3 张卡） | 与逆模因/删除同轴，做成"删掉一个概念"的困境比一棵树更好 |
| 空间阻断部 | 站点改造事件 | 与容量/站点系统重叠，做成"给 Site-XX 加一层空间锁" |
| 解明及研究部门 | 事件来源 | "已解明"是结果，不是过程 |
| 本质促动部 / 奇术部 / 神学部 | 并入数学 / 战术神学 / 炼金 | 三个都已有对应学科，分树会稀释 K 链解法 |

---

## 4. 元 / 彩蛋层

- **设计部门**：UI 主题的"第四面墙"彩蛋，一次性；
- **图像科**：模因/图像异常的事件包，不做部门；
- **神学部**：与战术神学合并，保留为 3 级分支。
