# 09 · UI 设计（v2：横排上下 + 右侧按钮群）

> 本版根据反馈重做布局：**去掉左右两条常驻侧栏**。上侧改为「资源条 + 预警横条」，下侧改为「事件横排」，右侧改为 CK3 式的**孤立按钮群**，点一下展开一块面板。
> 基准 1920×1080。

---

## 0. 这一版改了什么

| | v1 | v2 |
|---|---|---|
| 左栏 | 360px 常驻：K 级预警 + 帷幕 + 事件流 | **拆成两条横排**：顶部预警条（52px）+ 底部事件横排（96px） |
| 右栏 | 380px 常驻：部门树 + 详情 | **7 个 46×46 孤立按钮**，点击展开 520px 浮层面板 |
| 地图 | 被两栏夹住，可见 1180px | 全宽，只在打开面板时被遮住右侧 520px |
| 底部 | 科研/项目/档案/外交/统计 tab + 项目 chip | 事件卡横排 + 指令点 + 归档本月 |

一句话：**地图回到主角位置，其余全部变成"随叫随到"的浮层。**

## 1. 参考：Paradox 与 CK3

### 1.1 五款游戏的骨架

| 游戏 | 顶部 | 左侧 | 右侧 | 底部 | 地图模式 |
|---|---|---|---|---|---|
| **EU4** | 行政/外交/军事点、金币、人力 | 警报图标 | 出栈：军队、舰队、围城 | 政府/科技/理念/外交 | 政治/地形/宗教 |
| **HOI4** | 政治点、稳定、战争支持、工厂 | 国策树入口、决议 | 陆/海/空概览 | 生产、后勤、贸易、科研 | 政治/补给/前线 |
| **Stellaris** | 能源、矿物、合金、影响力、研究 | 局势日志 | 出栈：舰队、星球 | 政府/科技/传统/外交 | 政治/超空间/边界 |
| **CK3** | 金币、威望、虔诚、兵力 | 通知 | **右下按钮群**：领地/内阁/计谋/信仰/文化 | 角色肖像 + 快捷动作 | 政治/地形/信仰 |
| **Victoria 3** | GDP、生活水平、激进派、国库 | 日志 Journal | 出栈：州、军队、市场 | 人口/建筑/市场/科技 | 政治/资源/市场 |

### 1.2 CK3 真正值得抄的三件事

1. **按钮是孤立的，不是一条栏。** 每个按钮 46–52px，之间有间隙，有图标、有徽标、有悬停名。它们不占用连续的地图边缘，视觉上"浮"在角上。
2. **点开是一整块面板，不是抽屉。** 面板有标题、有内部分组、有关闭，覆盖地图一侧但保留地图可见。
3. **同一个按钮再点一次就关。** 不需要找 ×，肌肉记忆是"按回去"。

### 1.3 仍然要避开的三个坑

| 坑 | 表现 | 对策 |
|---|---|---|
| 数字通胀 | 顶栏 9 个数字，新手看不懂 | 分三簇 + 悬停明细 + 士气/资产默认折叠 |
| 模态嵌套 | 面板里再开面板，退不出来 | 层级 ≤2；开新面板自动关旧面板 |
| 信息与行动分离 | 日志告诉你出事，解决入口在别处 | 预警条自带「立案 / 处置」，直接进对应面板 |

## 2. 三条命题

### ① 地图不是战场，是"现实的状态"

没有单位、没有前线。只有站点 pin、热区、五种现实图层。玩家看地图是为了**发现哪里不对**，不是为了"下一步打哪"。

### ② 底部不是日志，是"待签字的东西"

事件卡横排在底栏，每张卡有类型、标题、倒计时和一条色标。点开即处置；不点，它就在那里等着过期。

### ③ 右侧不是栏，是"门"

七个按钮，七扇门。门后面才是树、详情、日程、票数。**平时不占地方，需要时才出现。**

## 4. 七个区

### 4.1 顶栏（60px）

三簇九个数字，默认折叠「士气」「资产」（虚化显示），悬停簇标题展开。右侧是日期 + 任期进度 + 设置。**没有速度控制**——回合制。

### 4.2 预警横条（52px）

单行，从红点开始：

`● K 级预警 · XK-17 人口普查 · [S2 显形] · ▓▓▓░░ 55/100 · 距不可逆 12 · [立案] [处置]` ｜ 右侧：`帷幕 78 ▼−2`、`待决 04`、`O5 例会 3 日`

- 未立案时**不显示时钟**，只写"存在无法归类的异常信号"。
- 只有一条 K 级预警的位置。多条时轮播，或显示 `+1`。
- 「处置」直接打开对应部门面板并预填任务。

### 4.3 地图

- 满屏，无遮挡。
- 大洲填充 `#141A20`，海洋只放标签。
- 站点 pin 7px 圆点 + 编号；K 级热区用红色径向渐变 + 脉冲 pin。
- 左上：`全球态势 / GLOBAL SITUATION / 第 23 月`。
- 右下（按钮群左侧）：五种地图模式竖排 36×36。
- 左下：当前模式图例，最多 4 项。

### 4.4 右侧按钮群

七个 46×46 的方块，间隙 9px，距右边缘 16px，从 y=150 开始：

| 按钮 | 打开的面板 | 徽标 |
|---|---|---|
| **部** | 部门树 + 详情 | 10 |
| **站** | 站点列表 + 容量 | — |
| **队** | 特遣队 | — |
| **O5** | 议会席位 + 投票 + 日程 | 3 |
| **研** | 科研树 + 进行中项目 | 3 |
| **档** | 档案检索 + 版本比对 | 2 |
| **外** | 外交 / GoI | — |

- 选中态：琥珀边框 + 淡琥珀底。
- 徽标：右上角 15px 圆角方块，红色=待处理，琥珀=可升级。
- 没有常驻文字标签，靠单字 + tooltip。

### 4.5 展开面板

- 520px 宽，上下各留 132px，右侧 86px。
- 右侧边缘有一个 12px 的**指针三角**，对准当前按钮中心——告诉你"这块面板是从那扇门出来的"。
- 结构：标题栏（名称 + 计数 + ×）→ 内容区（树/列表）→ 底部详情卡（选中项 + 两个动作）。
- 再点同一个按钮 → 关闭。ESC → 关闭。点另一个按钮 → 直接换内容，不叠层。

### 4.6 底部事件横排（96px）

- 左端：`04 / 待决事件`。
- 中间：事件卡横向排列，每张 250×62，超出部分裁切——**裁切本身就是"还有更多"的提示**。
- 每张卡：左侧 2px 色标（红=K 级、琥珀=政治、灰=日常）、类型行、标题、右侧倒计时。
- 右端：`●●●○ 4/4` 指令点 + `归档本月` 印章按钮。

### 4.7 Toast

顶部居中，最多 2 条，4 秒消失。点击跳到对应条目。

## 5. 交互

### 5.1 门 → 面板

| 操作 | 结果 |
|---|---|
| 点按钮 | 展开对应面板；按钮高亮；地图右侧被遮 520px |
| 再点同一个按钮 | 关闭面板 |
| 点另一个按钮 | 面板内容直接替换（不叠层） |
| 点面板里的树节点 | 底部详情卡更新 |
| 点地图 pin | 打开「站」面板并定位该站点 |
| 点预警条「处置」 | 打开对应部门面板并预填任务 |
| `Esc` | 关闭面板 |
| 双击按钮 | 全屏化面板（L3，可选） |

### 5.2 提请 vs 下达（意识形态的 UI 表达）

部门详情卡底部永远并排两个按钮：

| | 提请日程 | 下达任务 |
|---|---|---|
| 通道 | O5 议会 | 管理员办公室 |
| 耗时 | 2 回合 | 即时 |
| 成本 | 共识 −0~3 | 权威 −8 |
| 前置 | 需 7/13 票 | 无 |
| 收益 | 通过后权威减半；派系忠诚 +3 | 立即执行；O5-1 −8 |

**按钮形态随轴变化**：

- 民主锁定（L ≤ −60）：「下达」变灰，tooltip「您已没有这个权限。」
- 专制锁定（L ≥ +60）：「提请」变灰，tooltip「本制度不需要表决。」
- 中间地带：主按钮（实心）随轴偏移——偏专制时「下达」实心，偏民主时「提请」实心。

### 5.3 层级

| 层 | 形式 | 例子 |
|---|---|---|
| L1 | 地图浮卡 | 站点摘要、pin 详情 |
| L2 | 右侧面板 | 部门、O5、科研 |
| L3 | 全屏 | 档案阅读、结局 |

规则：最多两级叠加；开 L3 自动收 L1/L2。

### 5.4 Tooltip 三层

值 → 构成 → 六回合折线（按住 Alt）。

## 9. 可访问性

- 色盲：K 级红同时带脉冲与 `⚠`，不只靠颜色。

## 附录 B：v3 主题系统与地图交互

### B1. 大陆轮廓与悬停掩膜

地图从"纯点阵"升级为三层：

1. **`world-dots.png`**：透明底，点阵 + 大陆轮廓线。轮廓用 marching squares 从**同一套多边形**提取（1.8° 网格），所以线与点严格对齐，不会出现"线在点外飘"。
2. **`world-data.js`**：大陆/大洋的经纬度多边形 + Kavrayskiy VII 投影，地图生成器与界面共用一份数据。
3. **SVG 悬停区**：每个大陆/大洋一个 `<g>`，悬停时出现柔边掩膜（`blur(7px)`）并点亮标签。轮廓线本身不参与交互，只负责"看得清"。

| 对象 | 悬停效果 |
|---|---|
| 大陆 | 主题强调色 14% 填充 + 标签转为主文本色 |
| 大洋 | 信息色 8% 填充 + 标签提亮 |

调试参数：`01-main.html?hover=亚洲` 可强制高亮一个区域，方便截图与标注。

### B12. 控件材质重做（v12）

反馈是"按钮太简单"。查下来真正的问题不是形状不够复杂，而是**细节全落在 1px 以下、且没有厚度**：

| 旧实现 | 后果 |
|---|---|
| 细节 0.3–1.6px（刻线、铆钉） | 1× 下全部消失，只剩一根描边 |

4. **状态件**：LED 辉光 + 高光点、序号牌、左状态条。

### B16. 悬停掩膜修正（v16）

试玩反馈：**大洋高亮范围与真实地理差别太大，南极洲干脆不高亮**。查出两个不同的错：

**① 南极洲不是数据问题，是代码里被跳过。** 两个页面的地图脚本都写着：

```js
Object.keys(WORLD.CONTINENTS).forEach(function (k) {
  if (k === 'an') return;      // ← 南极洲从来没生成过掩膜
  ...
});
```

去掉这行即可；`add()` 顺带支持 `label: null`（南极洲、北冰洋贴着投影边缘，只给悬停不标字）。

**② 大洋掩膜是手画的，而且生成器里有 bug。** 大洋多边形原本是几段手写坐标，
换成 Natural Earth 的真数据后仍然不对——因为掩膜坐标是坏的。原因在简化函数：

> 先把经纬度投影成像素 → 在像素空间做 RDP → **再用"最近顶点下标"把简化后的点反查回经纬度**。

RDP 会跳过一整段平直海岸线，反查窗口（±3 个顶点）就搜不到对应的原始点，于是拿错经纬度，
掩膜变成一堆乱多边形。**画底图的 PNG 不受影响**（它直接用投影后的点，不反查），
所以"底图是对的、悬停是对的才怪"这个现象，正好是这个 bug 的指纹。

改法：直接在经纬度空间做 RDP（`eps=0.28°` ≈ 投影下 1.5 设备像素），不做任何反查。
`world-data.js` 从 123 KB 降到 **83 KB**，掩膜顶点 7160 → 4897。

**大洋数据**换成 `ne_110m_geography_marine_polys`：太平洋、大西洋、印度洋、北冰洋、南大洋，
按 Natural Earth 的 `ocean` 要素合并（南北太平洋/大西洋各并成一块）。
太平洋在图面上仍会被 180° 经线切成左右两瓣——这是投影决定的，不是 bug。

**验收**：`?hover=大西洋｜太平洋｜南极洲｜亚洲` 各渲一张，与无悬停的基准图做像素差，
检查命中区域是否落在正确的地理范围内。四个区域的差值图与真实轮廓吻合。

### B17. 悬停补全与站点标签（v17）

**① 海/湾并入大洋。** 只保留 7 个 `ocean` 要素时，地中海、加勒比海、黑海这些有名有姓的水域
谁都不管，鼠标落上去什么都不亮。把数据集里 **22 个 sea/bay/gulf** 按位置并入相邻大洋：

| 并入 | 海 / 湾 |
|---|---|
| 大西洋 | 地中海、黑海、加勒比海、墨西哥湾、拉布拉多海、哈德逊湾、巴芬湾 |
| 太平洋 | 菲律宾海、南海、日本海、鄂霍次克海、塔斯曼海、珊瑚海、阿拉斯加湾 |
| 印度洋 | 阿拉伯海、孟加拉湾、波斯湾、红海 |
| 北冰洋 / 南大洋 | 波弗特海 / 罗斯海、威德尔海 |
| 内陆水域 | 里海（唯一的纯内陆海，单列一组，只给悬停不标字） |

**② 空白兜底：最近区域查表。** 即使把所有海域都算上，自然数据的多边形仍然不铺满
（岛屿之间、近岸、极区有缝，实测还剩 **8.4%** 的图面点不亮）。做法：

1. 生成器把每个区域（6 组大洋 + 7 个大洲）栅格化成标签图；
2. 用 `scipy.ndimage.distance_transform_edt` 求出每个空白像素**最近的区域**；
3. 按 20×20 px 采成 **96×54** 的小表（`WORLD.NEAREST`，约 5 KB），界外的格子记 `.`；
4. 前端在地图最底层垫一个透明矩形接住这些空白，`mousemove` 时查表，给最近的区域加 `.force`。

于是"鼠标在地图上任何位置都有东西亮"成立，且亮的是**地理上最近的那块**，不是随便挑的。
抽样验证：地中海→大西洋、加勒比→北美洲、孟加拉湾→印度洋、波罗的海→欧洲、
波斯湾→亚洲、里海→内陆水域、南极近岸→南大洋。

**③ 站点标签。** 原来 10px、`--muted` 灰，压在地图点阵上根本看不清。改成：

- 字号 10 → **11.5px**，字重 600，字距 .05em；
- 颜色 `--pin-fg`：暗色主题用暖白 `#EFE4CC`，白主题反成 `#2C2822`；
- 加两层 `text-shadow`（1px 黑影 + 9px 扩散），保证压在任何点阵密度上都读得出来；
- 圆点 7 → 8px，外发光加强，`hot` 状态的标签改成偏白红而不是纯红。
