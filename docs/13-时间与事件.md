# 13 · 时间与事件引擎

> 给原型装上"会走的时间"和"能手动点的事件"。开局 **2026-11-20**，默认 **暂停**。

## 1. 时间模型

| 项 | 值 |
|---|---|
| 开局 | 2026-11-20 |
| 1 回合 | 1 个自然月，共 54 回合 |
| 速度 | 0（暂停）/ 1× / 2× / 4× |
| 1× 基准 | 400ms = 1 游戏日（一个月约 12 秒） |
| 显示 | 顶栏 `2026·11·20` 与 `任期 01/54`；时间轴、地图标题同步 |
| 位置 | 时间轴在**右上角日期栏下方**（`right:20 top:116 w:720`）；右侧导航下移到 168，部门面板同步下移，互不遮挡 |

速度默认 0：打开页面不会自己走，按 ▶ 或点 1×/2×/4× 才开始；再点一次当前速度即暂停。

## 2. 文件

| 文件 | 作用 |
|---|---|
| `mockups/engine.js` | 纯逻辑引擎，不碰 DOM；浏览器与 Node 共用同一份 |
| `mockups/events.js` | 测试事件目录（8 条，取自 `docs/05` 卡名） |
| `mockups/time-ui.js` | 时间轴 + 控制台，只调引擎方法 |
| `mockups/time.css` | 两者样式（不改 `v2.css`） |
| `tools/engine-test.mjs` | Node 测试，13 条 |

## 3. 引擎 API（后端接口）

```js
const e = Engine.create({ start: '2026-11-20', turns: 54, msPerDay: 400, seed: ['d01'] });

e.state();                 // { iso, day, speed, monthIndex, term, turns,
                           //   progress, pending, scheduled, nextEvent, log }
e.setSpeed(2);             // 0 / 1 / 2 / 4
e.tick(dtMs);              // UI 每帧调用；单次 dt 上限 500ms
e.advanceDays(n);
e.setDate('2027-01-01');
e.nextMonth();             // 归档本月
e.schedule('p01', 12);     // 12 天后自动触发；也接受 'YYYY-MM-DD'
e.trigger('d01');          // 手动触发
e.reset();
e.on('tick' | 'event' | 'speed' | 'date' | 'reset' | 'schedule', fn);
```

浏览器里是 `window.GameAPI`。控制台的每个按钮都只调这些方法——接真实后端时把 `create()` 换成 `fetch` 实现，UI 不用改。

## 4. 控制台

- `~` 或 `?console=1` 打开；
- **时间**：暂停 / 1× / 2× / 4×、+1 天、+1 月、重置；
- **事件**：8 条目录，点「触发」进入待决队列，同时更新底栏计数、预警条、提示条、事件面板与日志；
- **日志**：`D+n` 前缀，保留最近 24 条。

调试参数：

| 参数 | 作用 |
|---|---|
| `?console=1` | 打开控制台 |
| `?speed=1|2|4` | 初始速度 |
| `?date=2027-01-01` | 跳到指定日期（会结算逾期日程） |
| `?trigger=d01` | 载入即触发一条事件（冒烟测试） |
| `?freeze=1` | 不跑动画，截图用 |

## 5. 测试

```
node tools/engine-test.mjs
```

覆盖：初始状态、暂停不推进、400ms/天、跨月、跨年、跳日期结算、手动/日程事件、重置、4× 倍率、无效速度、月末边界。

## 6. 边界

- 单次 `tick` 的 dt 钳到 500ms：标签页挂起后回来不会一次跳掉几个月；
- `setDate` 向前跳会结算逾期日程，向后跳不会撤销已触发事件；
- 事件目录目前 8 条，`docs/05` 的 42 张卡尚未导入；
- 部门和资源数字现在由开局档案驱动（见 §7），不再是纯静态；
- 下一步接 `state.js`（见 `docs/12` §3 的数据契约）。

## 7. 开局档案（默认存档）

`mockups/save.js` 定义 `window.SAVE_DEFAULT`，这是"默认存档"的第一版：

| 字段 | 开局值 |
|---|---|
| `game.date` | 2026-11-20，第 1 回合，速度 0 |
| `world.threat` | **null**（未发现任何 K 级） |
| `world.veil` | 78，状态"正常"，delta 0 |
| `world.sites` | 19 个站点在线 |
| `world.pending` | `d02` 清洁工的加班单 / `d03` 新人的第一课 |
| `resources` | 经费 $120、编制 84、士气 65、容量 28、污染 08、资产 06、权威 60、共识 55 |

界面效果：

- 预警条切成**常态**：`态势评估 · 无 K 级预警 · 监测中 · 19 个站点在线 · 帷幕 78 · 正常`，立案/处置按钮隐藏；
- 顶栏 9 个资源数字、底栏与预警条的"待决"计数、帷幕数字都从存档读取；
- 待决面板只显示存档里有的 2 条，其余 4 条隐藏。

接后端时，`SAVE_DEFAULT` 换成存档接口返回的同样结构即可。
