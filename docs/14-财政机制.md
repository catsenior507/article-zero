# 14 · 财政机制

> 钱不是金币。钱是成员国对你的**信任额度**；黑账是它的影子。
> 本文只做设计，不含实现。实现切分见文末 M9。

---

## 0. 一句话

基金会不是缺钱，是缺一个**能签字的理由**。财政系统的目的不是让玩家攒钱，而是让"这笔钱从哪来、记在谁账上、被谁看见"变成每个月都要回答一次的问题。

---

## 1. 设计目标

1. **钱必须疼**：开局就是结构性赤字，不改革会在第 1 幕末见底。
2. **花钱即表态**：预算分配直接对应四根轴——集权/分权、守秘/揭露，在账面上就能看出来。
3. **两本账**：公开账维持合法性，黑账买"不能写进报告的行动"，两者比例决定审计风险。
4. **失败不是数字归零**：破产的结局是**被 O5 投票接管**，不是 Game Over 画面。
5. **不做通货膨胀模拟器**：只保留"成本随容量与污染上涨"这一条压力曲线，其余常数化。

---

## 2. 单位与开局

| 项 | 值 |
|---|---|
| 单位 | **百万美元**（$120 = 1.2 亿） |
| 开局储备 | **$120** |
| 开局月收入 | ≈ **$86.1**（拨款 71.7 + 企业 14.4） |
| 开局月支出 | ≈ **$90.6** |
| 开局净额 | **−$4.5 / 月**（结构性赤字） |
| 破产线 | 现金 < 0 且债务达上限，连续 3 回合 |

> 设计意图：$120 的储备大约撑 26 个月，正好是第 2 幕中段。玩家必须在第 1 幕内做出第一次取舍。

## 3. 六个机制

### 3.1 三条收入腿（基础层）

基金会不生产钱。它只有三条来路，每条对应一种不同的失败方式：

| 腿 | 稳定 | 规模 | 隐蔽 | 失败方式 |
|---|---|---|---|---|
| A 国家拨款 | 高 | 低 | 高 | 政治：条件被违背，钱被扣 |
| B 前台企业 | 中 | 高 | 中 | 慢性：抽成过高，帷幕一点点漏 |
| C 异常变现 | 低 | 极高 | 极低 | 急性：公众察觉，破幕事件 |

每月结算顺序：

```
A + B + C 到账
  → 固定支出（人事、设施、帷幕、行动待命、科研、杂项）
  → 预算缺口惩罚
  → 事件收支（K 级、赞助、罚款）
  → 净额进储备 / 透支进债务
```

#### A. 国家拨款

`40 + 0.30×帷幕 + 0.15×共识`，开局 **$71.7**。

五个主要捐赠方各占 20%，每个带一个条件（驻站 / 共享研究 / 沉默 / 不在其领土上变现异常 / 支持某次表决）。违背一个 → 该方停拨 **6 回合**（−20%）。集权轴可以施压换 +10% 收入，代价是共识 −2/月。

#### B. 前台企业

企业规模 `E`（1–5），月营收 `8×E`；抽成率 `r`（0–100%），基金会拿走 `8×E×r`。

开局：E=3、r=60% → 营收 24，抽成 **$14.4**。

代价：

- 帷幕衰减 = `max(0, r−50)/100 × 2.5` / 月（r=60 → 0.25；r=90 → 1.0）；
- r > 80 时曝光度 +1/月（监管开始注意）；
- 抽成越高，公司越像空壳，被调查的事件越容易触发。

扩张 +1 级 $40；卖掉一家 +$50、E−1、帷幕 −2。

#### C. 异常变现

把收容物变成现金流。每条可变现异常有 `yield`（$8–20/月）与 `exposure` 权重（1–3）：

- 启动成本 $5 + 一次部门行动；
- 每月 `+yield`，帷幕 `−0.6×exposure`，曝光度 `+1.5×exposure`；
- 曝光度（0–100）每月自然衰减 3；到 100 触发**破幕事件**：帷幕 −12、公开事件链、K 级抽取概率上升。

开局可变现异常为 **0**——它是中盘才出现的诱惑。三条同时变现每月多约 $36，但曝光度净增 6，约 17 个月后破幕。

> 这条腿故意做得"很赚"：它让缺钱的玩家有一个明确的、会后悔的选项。

三条腿的收益与代价可以对照成一张"每美元成本"表：

| 来源 | 每 $1 收入 | 帷幕/月 | 其它 |
|---|---|---|---|
| 拨款 | 1 | 0 | 政治条件 |
| 企业（r=60） | 1 | −0.25 | 调查事件 |
| 企业（r=90） | 1 | −1.0 | 曝光度 +1 |
| 异常（权重 2） | 1 | −1.2 | 曝光度 +3 |

**钱越"快"，帷幕掉得越快**——这是整个财政系统的中心句。

### 3.2 预算信封（选择层）

每月收入按五个信封分配，默认比例如下（可调，总和 100%）：

| 信封 | 默认 | 开局需求线 | 缺口后果 |
|---|---|---|---|
| 收容 | 33% | $30 | 容量上限 −2/月，事故概率 +5% |
| 人事 | 21% | $18 | 士气 −3/月；低于 35 触发罢工 |
| 帷幕 | 15% | $13 | 帷幕 −2/月（记忆删除不够） |
| 行动 | 12% | $10 | MTF 响应 +1 回合，K 级门槛更难 |
| 研究 | 10% | $8 | 部门进度停滞，等级无法提升 |
| 储备 | 9% | $7 | 无惩罚，但不进储备 |

规则：

- 缺口比例 = `(需求 − 实拨) / 需求`，惩罚按缺口比例线性缩放；
- 需求线随**站点数、容量、污染**上涨（见 §4）；
- 每幕开始时 O5 批准一次预算；**幕中调整**要付 `权威 −1 / 每 3%`，集权轴可以把这项成本减半，分权轴则免不了要走部门游说（共识 −2）。

### 3.3 双账与审计（张力层）

| 账 | 用途 | 风险 |
|---|---|---|
| 公开账 | 正常开支、部门预算、可见的收容 | 无 |
| 黑账 | 不能写进报告的行动（灭口、贿赂、非法实验） | 审计暴露 |

- 每月可把最多 **15% 的收入**转入黑账（集权 +5%，守秘 +3%，揭露 −5%）；
- 黑账支付"隐秘行动"时**不扣权威**，但会让黑账比例上升；
- 每 **6 回合**一次审计，暴露概率：

```
P = clamp(0.15 + 0.9 × 黑账余额/月收入 − 0.4×守秘轴, 0.05, 0.95)
```

- 暴露后果：`权威 −10、共识 −8`，并解锁一条"审计链"（3 个回合的选择，可花钱压下去）；
- 审计前可以把黑账"洗白"回公开账，但要付 10% 的手续费（洗钱成本）。

### 3.4 赤字与债务（失败层）

- 现金 < 0 时自动向成员国发行债券，**利率 2%/回合**，上限 **$150**；
- 债务每回合计息，可随时提前偿还；
- 债务 > $100 时，拨款公式额外 `−0.1×债务/10`（债主开始压价）；
- 连续 3 回合 `现金 < 0 且债务 = 上限` → 触发**接管投票**（见 §8）。

### 3.5 应急阀门（压力层）

两个一次性手段，都有明确代价：

| 手段 | 得到 | 付出 | 冷却 |
|---|---|---|---|
| 紧急拨款 | +$40 | 权威 −8、共识 −5 | 6 回合 |
| 变卖资产 | +$25 | 资产 −1（永久），帷幕 −2 | 无 |

紧急拨款在叙事上是一份**有你签名的文件**，元叙事层可以回收（觉醒度事件里被翻出来）。

### 3.6 赞助人（意识形态层）

每 9±3 回合出现一次"赞助人报价"：

```
+$35，条件三选一：
  A. 在其领土上设一个站点（容量 +4，帷幕 −3，主权争议）
  B. 共享一部分研究（研究 +1 级，共识 −6）
  C. 对某次事故保持沉默（帷幕 +5，若日后被揭露则共识 −12）
```

接受后条件写入存档；违背条件会在 3 回合内触发反噬。这是把"钱"直接接到意识形态轴上的接口：守秘轴更愿意接 C，揭露轴接了 C 就要准备付账。

## 4. 公式与数值

| 项 | 公式 | 开局 |
|---|---|---|
| 人事 | `18`（士气 < 40 时 ×1.2） | $18 |
| 设施 | `1.1 × 站点数 × (1 + 0.5×容量/40)` | $28.2 |
| 帷幕 | `8 + 0.2 × (100 − 帷幕)` | $12.4 |
| 行动 | `6` 待命；出动 $4/次（K 级 $10/次） | $6 |
| 科研 | `1.0 × Σ部门等级` | $22 |
| 杂项 | `4` | $4 |
| 合计支出 | — | $90.6 |

两条成本曲线：

```
设施系数 = 1 + 0.5 × 容量/40
帷幕维护 = 8 + 0.2 × (100 − 帷幕)
```

容量每 +8，设施 +$2.2；帷幕每掉 10 点，维护 +$2——**帷幕破了，修回来也更贵**。污染不进这两条公式，它通过 §5 的清理费与事故抬高账单。

注意"行动"是唯一随玩家操作跳动的支出：一次常规出动 $4、K 级出动 $10。调度特遣队不是免费的，这是"行动"信封存在的理由。

## 5. 与其它系统的耦合

| 系统 | 耦合方式 |
|---|---|
| 帷幕 | 拨款主项，也是帷幕维护的成本项；帷幕 < 50 时拨款延迟（收入 −20%，延后 1 回合到账） |
| 曝光度 | 异常变现与高抽成的产物；100 时破幕（帷幕 −12 + 公开事件链） |
| 污染 | 污染 > 60 时额外"清理费" $10/月；同时抬高破幕事件的触发频率 |
| 容量 | 推高设施维护；接近上限时新建站点要一次性 $30 |
| 部门 | 等级越高科研越贵；欠拨 → 进度停滞 → 关键事件无法解锁 |
| K 级 | 每条链有"应急开支"：立案 $15、处置 $25；不付则进度条减速；出动另计 $10/次 |
| 权威/共识 | 预算审批、紧急拨款、审计后果、捐赠方条件都走这两条 |
| 四轴 | 集权：幕中改预算便宜、黑账上限 +5%、可向捐赠方施压；分权：部门自行分配、重复建设 +10% 成本；守秘：审计概率 −0.4、异常变现曝光 ×0.8；揭露：黑账上限 −5%、但共识 +2/月 |

## 6. 一个月的流程

```
1. 月初：三条腿到账（拨款含捐赠方条件判定；企业按抽成结算；异常变现结算）
2. 固定支出扣除（人事 / 设施 / 帷幕 / 行动待命 / 科研 / 杂项）
3. 信封缺口惩罚结算
4. 玩家操作（部门、事件、K 级、出动）
5. 月末：归档 → 曝光度自然衰减 3 → 破幕判定 → 触发下月事件 → 生成财政报表
6. 每 6 回合：审计判定
7. 每幕开始：O5 预算审批
```

财政报表是一张**可截图的月度对账单**：收入三行（拨款/企业/异常）、支出六行、净额、储备、债务、黑账、曝光度、审计风险。它同时是玩家判断"这个月做错了什么"的唯一入口。

## 7. UI 形态

- **顶栏**：`$120` 后加涨跌箭头（已有 `.d` 位），赤字时数字变红；
- **财政面板**：五个页签——总账 / 收入 / 预算 / 债务 / 黑账；
- **总账页**：本月对账单 + 三条收入腿的占比条 + 曝光度条；
- **收入页**：拨款（含五个捐赠方的条件与状态）、企业规模与抽成率、可变现异常列表；
- **预算页**：五条横向滑块，实时显示缺口与后果；改动超过阈值时出现"权威 −N"的确认；
- **黑账页**：一个比例旋钮 + 审计风险条（0–100%）；
- **月末**：报表以一张"对账单"浮层出现，可关闭，可在档案里回看。

## 8. 失败与结局

| 状态 | 触发 | 结果 |
|---|---|---|
| 接管投票 | 现金 < 0 且债务满，连续 3 回合 | O5 表决；失败则进入"被罢免"结局，游戏不结束，改为旁观者视角看完剩余回合 |
| 审计链 | 审计暴露 | 3 回合选择：认罚 / 洗钱 / 灭口，各有代价 |
| 罢工 | 士气 < 35 且人事缺口 > 30% | 站点停摆 2 回合，容量 −4 |
| 盈余 | 连续 6 回合净额 > 0 | 可一次性买容量（$30/2 点）或帷幕（$20/1 点） |

没有"财务胜利"结局。盈余只是让你多撑一会儿。

## 9. 为什么不是普通资源管理

普通 4X 的钱是**生产—消费**循环；本作的钱是**合法性**的计量：

- 收入不来自生产，来自"别人还愿意相信你"；
- 黑账让你能做不能说的事，但它把"说"的成本推迟到未来；
- 每一笔紧急拨款都留签名，元叙事层会把它翻出来；
- 预算不是优化题，是**你愿意让哪个部门先坏掉**的排序题。

如果最后做出来只是"每月 +5 金币、花 20 金币建楼"，这个设计就失败了。

## 10. 待你确认的 8 个决策

1. **单位**：百万美元、开局 $120（=1.2 亿）是否合适？还是想用更抽象的"经费点"？
2. **开局赤字**：−$4.5/月（约 26 个月见底）是否太狠？可改为 −2 或持平。
3. **信封数量**：五个是否太多？可以砍到三个（收容 / 人事 / 帷幕），行动与研究并入。
4. **黑账**：独立页签，还是并进总账只显示一个比例？
5. **审计频率**：6 回合一次，还是只在特定事件后触发？
6. **曝光度**：异常变现用独立的曝光度轨道（本文方案），还是直接扣帷幕？
7. **企业上限**：抽成率允许拉到 100%（杀鸡取卵）吗？还是封顶 90%？
8. **捐赠方条件**：五个国家的条件写死（驻站/研究/沉默…），还是抽象成 5 个"条件槽"由事件填充？
