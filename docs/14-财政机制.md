# 14 · 财政机制

> 钱不是金币。钱是成员国对你的**信任额度**；黑账是它的影子。
> 本文只做设计，不含实现。实现切分见文末 M9。

---

## 0. 一句话

基金会不是缺钱，是缺一个**能签字的理由**。财政系统的目的不是让玩家攒钱，而是让"这笔钱从哪来、记在谁账上、被谁看见"变成每个月都要回答一次的问题。

---

## 1. 设计目标

1. **钱必须疼**：开局就是结构性赤字，不改革会在第 1 幕末见底。
2. **花钱即表态**：预算分配直接对应四根轴——集权/分权、守秘/揭露，在账面上就能看出来。
3. **两本账**：公开账维持合法性，黑账买"不能写进报告的行动"，两者比例决定审计风险。
4. **失败不是数字归零**：破产的结局是**被 O5 投票接管**，不是 Game Over 画面。
5. **不做通货膨胀模拟器**：只保留"成本随容量与污染上涨"这一条压力曲线，其余常数化。

---

## 2. 单位与开局

| 项 | 值 |
|---|---|
| 单位 | **百万美元**（$120 = 1.2 亿） |
| 开局储备 | **$120** |
| 开局月收入 | ≈ **$86** |
| 开局月支出 | ≈ **$91** |
| 开局净额 | **−$5 / 月**（结构性赤字） |
| 破产线 | 现金 < 0 且债务达上限，连续 3 回合 |

> 设计意图：$120 的储备大约撑 24 个月，正好是第 2 幕中段。玩家必须在第 1 幕内做出第一次取舍。

---

## 3. 六个机制

### 3.1 月度收支（基础层）

每月结算一次，顺序固定：

```
收入（拨款 + 前台企业）
  → 固定支出（站点、薪资、记忆删除、部门、杂项）
  → 预算信封的缺口惩罚
  → 事件收支（K 级、赞助、罚款）
  → 净额进储备 / 透支进债务
```

收入来源只有两条，都**不是玩家直接控制**的：

| 来源 | 公式 | 开局 |
|---|---|---|
| 成员国拨款 | `40 + 0.30×帷幕 + 0.15×共识` | $71.7 |
| 前台企业 | `10 + 0.80×资产` | $14.8 |

这决定了本作的经济基调：**你不能"赚钱"，你只能让拨款不要减少**。帷幕掉 10 点，月收入少 $3；共识掉 20，少 $3。所有"省钱"的手段本质都是在动帷幕或共识。

### 3.2 预算信封（选择层）

每月收入按五个信封分配，默认比例如下（可调，总和 100%）：

| 信封 | 默认 | 开局需求线 | 缺口后果 |
|---|---|---|---|
| 收容 | 33% | $30 | 容量上限 −2/月，事故概率 +5% |
| 人事 | 21% | $18 | 士气 −3/月；低于 35 触发罢工 |
| 帷幕 | 15% | $13 | 帷幕 −2/月（记忆删除不够） |
| 行动 | 12% | $10 | MTF 响应 +1 回合，K 级门槛更难 |
| 研究 | 10% | $8 | 部门进度停滞，等级无法提升 |
| 储备 | 9% | $7 | 无惩罚，但不进储备 |

规则：

- 缺口比例 = `(需求 − 实拨) / 需求`，惩罚按缺口比例线性缩放；
- 需求线随**站点数、容量、污染**上涨（见 §4）；
- 每幕开始时 O5 批准一次预算；**幕中调整**要付 `权威 −1 / 每 3%`，集权轴可以把这项成本减半，分权轴则免不了要走部门游说（共识 −2）。

### 3.3 双账与审计（张力层）

| 账 | 用途 | 风险 |
|---|---|---|
| 公开账 | 正常开支、部门预算、可见的收容 | 无 |
| 黑账 | 不能写进报告的行动（灭口、贿赂、非法实验） | 审计暴露 |

- 每月可把最多 **15% 的收入**转入黑账（集权 +5%，守秘 +3%，揭露 −5%）；
- 黑账支付"隐秘行动"时**不扣权威**，但会让黑账比例上升；
- 每 **6 回合**一次审计，暴露概率：

```
P = clamp(0.15 + 0.9 × 黑账余额/月收入 − 0.4×守秘轴, 0.05, 0.95)
```

- 暴露后果：`权威 −10、共识 −8`，并解锁一条"审计链"（3 个回合的选择，可花钱压下去）；
- 审计前可以把黑账"洗白"回公开账，但要付 10% 的手续费（洗钱成本）。

### 3.4 赤字与债务（失败层）

- 现金 < 0 时自动向成员国发行债券，**利率 2%/回合**，上限 **$150**；
- 债务每回合计息，可随时提前偿还；
- 债务 > $100 时，拨款公式额外 `−0.1×债务/10`（债主开始压价）；
- 连续 3 回合 `现金 < 0 且债务 = 上限` → 触发**接管投票**（见 §8）。

### 3.5 应急阀门（压力层）

两个一次性手段，都有明确代价：

| 手段 | 得到 | 付出 | 冷却 |
|---|---|---|---|
| 紧急拨款 | +$40 | 权威 −8、共识 −5 | 6 回合 |
| 变卖资产 | +$25 | 资产 −1（永久），帷幕 −2 | 无 |

紧急拨款在叙事上是一份**有你签名的文件**，元叙事层可以回收（觉醒度事件里被翻出来）。

### 3.6 赞助人（意识形态层）

每 9±3 回合出现一次"赞助人报价"：

```
+$35，条件三选一：
  A. 在其领土上设一个站点（容量 +4，帷幕 −3，主权争议）
  B. 共享一部分研究（研究 +1 级，共识 −6）
  C. 对某次事故保持沉默（帷幕 +5，若日后被揭露则共识 −12）
```

接受后条件写入存档；违背条件会在 3 回合内触发反噬。这是把"钱"直接接到意识形态轴上的接口：守秘轴更愿意接 C，揭露轴接了 C 就要准备付账。

## 4. 公式与数值

| 项 | 公式 | 开局 |
|---|---|---|
| 站点维护 | `1.1 × 站点数 × (1 + 0.5×容量/40)` | $28.2 |
| 薪资 | `18`（士气 < 40 时 ×1.2） | $18 |
| 记忆删除 | `7 + 0.7×污染` | $12.6 |
| 部门预算 | `1.2 × Σ部门等级` | $26.4 |
| 杂项 | `6` | $6 |
| 合计支出 | — | $91.2 |

成本压力只有一条曲线：

```
站点维护系数 = 1 + 0.5 × 容量/40
记忆删除系数 = 1 + 0.7 × 污染/100
```

容量每 +8，维护 +$2；污染每 +10，记忆删除 +$7。真正的扩张成本在**新建站点一次性 $30** 与污染带来的长期账单。**收容越多，越养不起**——这是本作财政的核心张力。

---

## 5. 与其它系统的耦合

| 系统 | 耦合方式 |
|---|---|
| 帷幕 | 收入的主项；帷幕 < 50 时拨款延迟（收入 −20%，延后 1 回合到账） |
| 污染 | 直接推高记忆删除成本；污染 > 60 时额外"清理费" $10/月 |
| 容量 | 推高站点维护；接近上限时新建站点要一次性 $30 |
| 部门 | 等级越高越贵；欠拨 → 进度停滞 → 关键事件无法解锁 |
| K 级 | 每条链有"应急开支"：立案 $15、处置 $25；不付则进度条减速 |
| 权威/共识 | 预算审批、紧急拨款、审计后果都走这两条 |
| 四轴 | 集权：幕中改预算便宜、黑账上限 +5%；分权：部门自行分配、重复建设 +10% 成本；守秘：审计概率 −0.4；揭露：黑账上限 −5%、但共识 +2/月 |

## 6. 一个月的流程

```
1. 月初：拨款到账（含延迟判定）
2. 固定支出扣除
3. 信封缺口惩罚结算
4. 玩家操作（部门、事件、K 级）
5. 月末：归档本月 → 触发下月事件 → 生成财政报表
6. 每 6 回合：审计判定
7. 每幕开始：O5 预算审批
```

财政报表是一张**可截图的月度对账单**：收入两行、支出五行、净额、储备、债务、黑账、审计风险。它同时是玩家判断"这个月做错了什么"的唯一入口。

---

## 7. UI 形态

- **顶栏**：`$120` 后加涨跌箭头（已有 `.d` 位），赤字时数字变红；
- **财政面板**：从右侧门或底栏"档案"旁进入，四个页签——总账 / 预算 / 债务 / 黑账；
- **预算页**：五条横向滑块，实时显示缺口与后果；改动超过阈值时出现"权威 −N"的确认；
- **黑账页**：一个比例旋钮 + 审计风险条（0–100%）；
- **月末**：报表以一张"对账单"浮层出现，可关闭，可在档案里回看。

## 8. 失败与结局

| 状态 | 触发 | 结果 |
|---|---|---|
| 接管投票 | 现金 < 0 且债务满，连续 3 回合 | O5 表决；失败则进入"被罢免"结局，游戏不结束，改为旁观者视角看完剩余回合 |
| 审计链 | 审计暴露 | 3 回合选择：认罚 / 洗钱 / 灭口，各有代价 |
| 罢工 | 士气 < 35 且人事缺口 > 30% | 站点停摆 2 回合，容量 −4 |
| 盈余 | 连续 6 回合净额 > 0 | 可一次性买容量（$30/2 点）或帷幕（$20/1 点） |

没有"财务胜利"结局。盈余只是让你多撑一会儿。

---

## 9. 为什么不是普通资源管理

普通 4X 的钱是**生产—消费**循环；本作的钱是**合法性**的计量：

- 收入不来自生产，来自"别人还愿意相信你"；
- 黑账让你能做不能说的事，但它把"说"的成本推迟到未来；
- 每一笔紧急拨款都留签名，元叙事层会把它翻出来；
- 预算不是优化题，是**你愿意让哪个部门先坏掉**的排序题。

如果最后做出来只是"每月 +5 金币、花 20 金币建楼"，这个设计就失败了。

---

## 10. 待你确认的 5 个决策

1. **单位**：百万美元、开局 $120（=1.2 亿）是否合适？还是想用更抽象的"经费点"？
2. **开局赤字**：−$5/月（约 24 个月见底）是否太狠？可改为 −2 或持平。
3. **信封数量**：五个是否太多？可以砍到三个（收容 / 人事 / 帷幕），行动与研究并入。
4. **黑账**：独立页签，还是并进总账只显示一个比例？
5. **审计频率**：6 回合一次，还是只在特定事件后触发？
