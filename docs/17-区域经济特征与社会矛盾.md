# 17 · 区域经济特征与社会矛盾

> `docs/16` 给了区域系数表，但没说**这些系数为什么长这样**。本文补上底层：每个区域有一组硬指标（产业、贫富、就业、城镇化），系数由它们推导；每月在硬指标核心上下做正态分布漂移，而不是让系数自己乱走。

---

## 0. 一句话

**成本是结果，不是设定。** 一个地方贵，是因为它的人工贵、电价贵、或者社会太乱要加安保；这些都能被玩家看见、被事件改写。

---

## 1. 十个硬指标

| 指标 | 含义 | 影响 |
|---|---|---|
| `gdpPerCapita` | 人均 GDP（美元） | 媒体、安保、建设、消费价格 |
| `mfgWage` | 制造业全成本时薪（美元） | 人工成本的主项 |
| `elecPrice` | 工业电价（美分/kWh） | 设施电力、重工业成本 |
| `constructionIndex` | 建设成本指数（美国=1） | 设施维护、新建站点 |
| `urbanization` | 城镇化率 | 媒体触达、建设难度、招募 |
| `gini` | 基尼系数 | 阶级矛盾、腐败、安保需求 |
| `unemployment` | 失业率 | 招募成本、社会张力、罢工 |
| `informality` | 非正规就业占比 | 腐败、漏损、监管难度 |
| `sectors` | 产业构成（农业/采掘/重工/轻工/服务/金融/科技） | 能源需求、人工结构、抗冲击能力 |
| `tensions` | 五维社会矛盾（阶级/族群/宗教/地域/代际） | 稳定度、事件概率、帷幕成本 |

前九个是"经济"，最后一个是"社会"。**成本系数全部由这十个推导**，不再手设。

## 3. 社会矛盾的五种后果

| 维度 | 高的时候会发生什么 |
|---|---|
| 阶级 | Gini 高 + 失业高 → **罢工**（站点停摆 2 回合、容量 −2）；但人工便宜 |
| 族群 | 站点遭袭、内部渗透概率上升；本地雇员忠诚度下降 |
| 宗教 | 收容物被当作神迹/禁忌，**帷幕泄漏**风险 +30% |
| 地域 | 分离主义：站点所在国可能**冻结资产**或要求移交 |
| 代际 | 青年失业 → 抗议、网络泄密；科技部门招募困难 |

这些不是纯叙事：每条都挂一个事件概率与一个成本修正。

## 4. 从硬指标推导成本系数

```
labor        = 0.20 + 0.80 × (mfgWage / 50.8)
energy       = elecPrice / 8.51
construction = constructionIndex
media        = 0.40 + 0.60 × (gdp/65000)^0.5 × urbanization
security     = 0.50 + 0.50 × (gdp/65000)^0.5 + 0.40 × tension
corruption   = 0.03 + 0.50 × informality + 0.15 × tension
stability    = 0.98 − 0.30×tension − 0.25×unemployment − 0.25×informality
```

代入 §2 的初值：

| 区域 | labor | constr | energy | media | security | corr | stability |
|---|---|---|---|---|---|---|---|
| 北美 | 1.00 | 1.00 | 1.00 | 0.90 | 1.12 | 0.12 | 0.86 |
| 欧洲 | 1.07 | 1.24 | 2.00 | 0.82 | 1.08 | 0.14 | 0.84 |
| 亚洲 | 0.39 | 0.55 | 1.06 | 0.55 | 0.90 | 0.37 | 0.69 |
| 南美 | 0.33 | 0.50 | 1.41 | 0.58 | 0.84 | 0.31 | 0.73 |
| 非洲 | 0.25 | 0.45 | 1.65 | 0.45 | 0.80 | 0.51 | 0.60 |
| 大洋洲 | 1.02 | 1.10 | 1.41 | 0.90 | 1.07 | 0.12 | 0.88 |
| 南极 | 2.09 | 3.00 | 4.70 | 0.00 | 2.00 | 0.04 | 0.45 |

> 南极无本地经济，`media=0`、`security` 与 `construction` 手设为 2.0 / 3.0，作为纯输入成本区。
> 这套值是运营值；`docs/16` §3.2 的手设表作为首月快照保留，首月结算后由公式覆盖。

## 5. 漂移：在核心上下做正态分布

每个硬指标存三个数：

```js
{ core: 65000, value: 64870, sigma: 0.008 }
```

- `core`：长期核心（结构决定的"真值"）；
- `value`：本月观测值（显示与计算用）；
- `sigma`：月度波动率（按指标类型给）。

每月结算：

```
value = core + φ × (value − core) + core × N(0, sigma)
```

- `φ = 0.5`：一半回归核心，一半保留上月扰动；
- `N(0, sigma)`：正态分布，用 Box-Muller 生成；
- 结果夹在 `[core×0.80, core×1.20]`，防止连续极端值把账打穿。

σ 的初值：

| 指标 | σ/月 | 理由 |
|---|---|---|
| gdpPerCapita | 0.8% | 年化约 ±2.8% |
| mfgWage | 1.0% | 工资黏性略高 |
| elecPrice | 3.0% | 能源最波动 |
| constructionIndex | 1.5% | 建材与人工 |
| urbanization | 0.2% | 几乎不动 |
| gini | 0.5% | 收入结构慢变 |
| unemployment | 5.0% | 就业数据噪声大 |
| informality | 2.0% | 缓慢漂移 |
| tensions（五维） | 3.0% | 社会情绪短周期 |

**关键点**：系数不独立漂移。labor 变了，一定是因为 mfgWage 变了；玩家在报表里能看到"这个月欧洲贵了，因为电价涨了 6%"，而不是"数字随机跳了"。

---

## 6. 核心位移：只有结构性事件才动 core

| 事件 | 对 core 的影响 |
|---|---|
| 战争 / 政变 | gdp ×0.80、construction +30%、stability −0.20 |
| 产业转移 | gdp ×1.10、unemployment −2%、mfgWage +4% |
| 金融危机 | gini +0.05、unemployment +4%、informality +5% |
| 大规模镇压 | tension −0.10、stability +0.05，但 legitimacy − |
| 基建投资 | construction −10%、gdp ×1.05、unemployment −1% |
| 疫情 / 灾害 | gdp ×0.92、informality +3%、tension +0.05 |

核心位移是**永久**的（写回 `core`），值位移是**临时**的（只改 `value`）。这是"经济发展"与"月度波动"的区别。

### 玩家能做的：发展援助

花钱改核心，这是财政与区域系统的接口：

| 投入 | 效果 | 副作用 |
|---|---|---|
| $20M 基建 | gdp ×1.05、construction −5% | 3 个月后人工 +3% |
| $15M 教育 | unemployment −1%、tech +1% | 5 个月后 mfgWage +4% |
| $10M 维稳 | tension −0.05 | gini +0.01（镇压的代价） |

**发展会让自己变贵**——这是本作区域经济最想说的那句话。

## 7. 存档结构

```js
regions: {
  eu: {
    core: { gdpPerCapita: 55000, mfgWage: 55.0, elecPrice: 17.0,
            constructionIndex: 1.24, urbanization: 0.76, gini: 0.32,
            unemployment: 0.06, informality: 0.12,
            sectors: { agri: 0.04, extract: 0.01, heavy: 0.10, light: 0.08,
                       services: 0.70, finance: 0.05, tech: 0.02 },
            tensions: { class: 0.35, ethnic: 0.30, religion: 0.20,
                        regional: 0.35, generation: 0.28 } },
    value: { /* 同结构，本月观测 */ },
    sigma: { gdpPerCapita: 0.008, mfgWage: 0.010, elecPrice: 0.030,
             constructionIndex: 0.015, urbanization: 0.002, gini: 0.005,
             unemployment: 0.050, informality: 0.020, tensions: 0.030 },
    derived: { labor: 1.07, construction: 1.24, energy: 2.00,
               media: 0.82, security: 1.08, corruption: 0.14, stability: 0.84 },
    history: [ /* 最近 12 个月的值与系数 */ ]
  }
}
```

规则：

- `sigma` 存进存档，不同难度可以调（硬核模式 σ ×1.5）；
- `history` 保留 12 个月，报表可回溯"为什么这个月贵"；
- 随机数用存档里的 `seed` 派生，读档后重算结果一致；
- 迁移：旧存档没有 `core/value` 时，用 `derived` 反推一个近似 core。

## 8. 一个月的漂移示例（欧洲）

| 指标 | 上月 | 核心 | 本月 | 变化 |
|---|---|---|---|---|
| gdp | 55,000 | 55,000 | 54,760 | −0.44% |
| mfgWage | 55.0 | 55.0 | 55.6 | +1.1% |
| elecPrice | 17.0 | 17.0 | 18.1 | +6.5% |
| gini | 0.320 | 0.320 | 0.318 | −0.6% |
| unemployment | 6.0% | 6.0% | 6.3% | +0.3pp |

推导结果：labor 1.07→1.08、energy 2.00→2.13、stability 0.84→0.83。
报表一句话：**"欧洲本月贵了 2.1%，主要是电价涨了 6.5%。"**

## 9. UI

区域页（`docs/16` §6 的那一页）扩成三段：

1. **特征**：人均 GDP、Gini、失业、城镇化、产业条（七段堆叠）；

## 10. 待确认

1. **区域粒度**：七大洲下，亚洲内部差异极大（中国 vs 日本 8 倍），要不要拆成"东亚/南亚/中东"？
2. **σ 幅度**：每月 gdp ±0.8%、电价 ±3%，是否够/过？
3. **发展援助**：$20M 换 +5% GDP 是否太便宜？这会成为玩家的"刷钱"路径吗？
4. **张力权重**：阶级 0.30 / 族群 0.25 / 宗教 0.15 / 地域 0.20 / 代际 0.10，是否合理？
5. **随机种子**：读档重算一致（确定性）还是每次读档重新抽（更"活"）？
