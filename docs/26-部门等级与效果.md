# 26 · 部门等级与效果

> 14 个可培养部门 + 末日学部（本作原创）+ 2 个辅助部门，各有 1–5 级。等级不是数字，是**各自系统的旋钮**：延续部管帷幕，末日学部管 K 级预警，数学部管科研速度。

---

## 1. 等级与升级

| 项 | 规则 |
|---|---|
| 等级范围 | 1–5（开局多数 1–3） |
| 升级成本 | `6 + 4 × 当前等级`（$M）：L1→2 $10、L2→3 $14、L3→4 $18、L4→5 $22 |
| 支付 | 从顶栏经费现金扣，不占月度预算 |
| 上限 | 5 级；满级后按钮禁用 |
| 存档 | `world.org.levels[deptId]` |

升级是**即时**的：点一下扣钱、加一级，效果立刻写进面板与后续结算。

## 3. 三条主干

用户最关心的三条，单独说明：

### 3.1 帷幕 ← 延续部

```
帷幕月衰减 = 0.5 − 0.1 × 延续部等级
帷幕上限   = 95 + 1 × 延续部等级
```

L1 时每月掉 0.4、上限 96；L5 时每月掉 0（不再自然衰减）、上限 100。
**延续部是唯一能把帷幕"止漏"的部门**，所以它的等级比任何一次应急拨款都值钱。

### 3.2 K 级防范 ← 末日学部

```
K 级预警天数 = 3 + 1 × 末日学部等级
处置成本     = 基础成本 × (1 − 0.04 × 等级)
```

L1 时提前 4 天看到征兆；L5 时提前 8 天、处置便宜 20%。
预警天数直接决定玩家能不能在 S0 阶段做反应——这是"多活一回合"的另一种写法。

### 3.3 科研速度 ← 数学部 / 超形上学 / 炼金

```
科研速度 = 100% + 5% × 数学部 + 6% × 超形上学 + 2% × 炼金
```

三个部门都点满时 +65%。这意味着**同样的 54 回合，能多跑出约三分之二的项目**——但代价是 3 × 22 = $66M 的升级费，相当于 4.6 个月的盈余。

## 5. 存档

```js
world.org.levels = {
  ops: 4, anti: 2, pata: 3, math: 3, dt: 2, theo: 2, misc: 2,
  raisa: 3, proc: 3, alch: 2, del: 1, cont: 1, decom: 1, aeed: 1,
  crypto: 2, aiad: 2, esch: 2
}
```

升级只改这一个对象；效果是纯函数 `f(level)`，不另存快照，避免"等级与效果对不上"。
