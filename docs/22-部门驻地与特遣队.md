## 1. 自拟规则

1. **一支特遣队只能有一个主管部门**（避免"谁都能调"）；
2. 特遣队的**基地可以不在主管部门的总部**（Beta-777 就是例子）；
3. 部门的**总部站点被攻破** → 部门降 1 级、该部门所有特遣队停摆 2 回合；
4. 调动特遣队需要主管部门等级 ≥ 2；K 级出动需要 ≥ 3；
5. O5 与伦理的直属队不受部门等级限制，但每回合只能各调一次。

## 5. 这套关系怎么影响玩法

| 关系 | 效果 |
|---|---|
| 部门 → 总部 | 总部被攻破：部门 −1 级、所属 MTF 停摆 2 回合 |
| 总部 → 区域 | 总部所在区域的社会张力，会成为该部门事件的背景 |
| 特遣队 → 部门 | 出动要部门等级；部门降级，特遣队跟着变弱 |
| 特遣队 → 基地 | 基地失守，特遣队需要 3 回合转移 |
| Site-0 | 删除部不占地图，任何"攻破 Site-0"的选项都不存在 |

## 6. 存档结构

```js
org: {
  departments: [
    { id: 'pata', hq: 'S-87', level: 3, mtfs: ['lambda5'] },
    { id: 'del',  hq: 'S-0',  level: 1, mtfs: [] }
  ],
  sites: [
    { id: 'S-87', region: 'na', hosts: ['pata'], status: 'normal' }
  ],
  mtfs: [
    { id: 'lambda5', dept: 'pata', base: 'S-87', source: 'inferred', ready: true }
  ]
}
```

静态定义（名称、隶属、来源标记）放在 `mockups/org.js`；可变状态（等级、状态、停摆）放存档。
