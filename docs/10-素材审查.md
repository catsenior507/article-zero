# 10 · 素材审查（v12）

> 起因：反馈"按钮太简单了"。这一轮先把工作区里的素材逐类查了一遍，再重画控件。
> 结论：**按钮的问题不在"形状不够花"，而在"没有材质"**——边光只有 1.2px 的白线，铆钉 1.4px，1× 下全部消失，七种控件读起来都是同一根描边框。

---

## 1. 查出来的问题

### 1.1 控件（按钮）

| # | 问题 | 证据 |
|---|---|---|
| 1 | **同级控件材质密度不一致** | 面板动作（`frame-btn`）有 8 层，导航（`frame-rail`）只有 5 层，齿轮（`frame-gear`）3 层 |
| 2 | **方形内凹压在八角板上** | `btn-rail` 用 `rect 26×26` 做内凹，四个方角与八角轮廓打架；1× 下像"方框套八角" |
| 3 | **细节尺寸低到看不见** | 铆钉 `r=1.4~1.6`、刻线 0.3px、拉丝纹理 `.03` 透明度；1920×1080 下全部消失 |
| 4 | **只有"线"，没有"边"** | 外板顶边一条 1.2px 白线 + 底边一条色线，没有厚度；所以读起来是描边框而非实体件 |
| 5 | **主/次按钮没有形体差** | 预警条「立案」「处置」形体完全相同，只差文字颜色；次要按钮该降饱和、主按钮该有状态条 |
| 6 | **旧 CSS 残留矩形** | `.abtn.primary{background: color-mix(…8%)}` 没被 v5 重置覆盖，六角按钮背后透出一块矩形底 |
| 7 | **母版与 sprite 已漂移** | `btn-alert.svg` 76×26 / sprite 76×28；`btn-action` 240×36 → 240×44；`btn-stamp` 150×46 → 150×52 |
| 8 | **三份手抄副本** | `assets/ui/*.svg`（母版）、`icons.js`（运行时）、`icons.svg`（标称同源）三者各改各的 |

### 1.2 部门徽记（`assets/scp/`）

- **规格散**：20 张里 18 张 PNG、2 张 SVG（`DeDLogo.svg`、`department-of-other.svg`）；尺寸从 `antimemetics-division.png` 100×100 到 `dept.png` 2400×2400，实际显示尺寸 **18px**。
- **用法依赖"反相 + screen"**：`img.em{filter:invert(1); mix-blend-mode:screen}`。这对"深色图形 + 白底/透明底"成立（白底在 screen 下会让位，不会变成方块），我按这条管线做了合成模拟，四张可疑图都能出白色图形——**不是坏图，是太细**。
- **18px 下糊成一团**：O5 议会、超形上学部、数学部这类同心徽记，缩到 18px 只剩一个亮斑；而同排的「站」「采」「炼」用的是文字徽章——**两套表达混用**，一行里有的有框有的没有。
- **尺寸不一致**：文字徽章 16px 带边框，图片徽章 18px 无边框（已统一为 16px + 同款边框）。

## 2. 这一轮改了什么

### 2.1 重新定义材质（六个母版全部重画）

放弃"堆层数"，改成四段式，并要求每段在 1× 下都能看见：

1. **边光**：色晕 2.4–3.6px（半透明主题色）+ 金属渐变描边 1.1–1.9px（顶部白 → 中部黑 → 底部更黑）。
   这是本轮最关键的一条——一条渐变描边就把"描边框"变成"有厚度的金属边"。
2. **内凹**：真正的内凹面（顶部深、底部回弹光），八角控件用八角内凹，不再用方框。
3. **五金**：带槽螺钉（暗底 + 亮圈 + 一道斜槽）、对接槽、冲孔、铆钉，尺寸提到 1.7–2.7px。
4. **状态件**：LED + 辉光 + 高光点、序号牌、状态条。

逐件改动：

| 控件 | 改动 |
|---|---|
| `btn-rail` 导航 | 方内凹→八角内凹；加左侧对接槽、四颗带槽螺钉、**底部序号牌**（`01`–`07` 从角落挪进牌里） |
| `btn-mode` 图层 | 加金属边光、左右卡槽、独立灯座 + LED 高光点 |
| `btn-gear` 齿轮 | 边光 + 内缩线 + 中心环（28px，只做能看见的三件事） |
| `btn-alert` 预警 | 六角改**对称**（原来右尖角在 y=12、左尖角在 y=14，偏了 2px）；左侧加状态条、四铆钉、右端 chevron |
| `btn-action` 动作 | 铭牌内斜面 + 端头刻线、螺钉开槽、底部刻度、图标井光圈、LED 辉光 |
| `btn-stamp` 印章 | 三层框（外板 / 双线 / 压痕）+ 上下各 5 个冲孔 + 两侧螺钉 |

### 2.2 一份真源，两个产物

新增 `assets/ui/build-icons.mjs`：

```
assets/ui/*.svg (母版)  ──build-icons.mjs──▶  assets/icons.js  ──▶  assets/icons.svg
```

- 生成时自动：去掉深色预览底、去掉固定宽高只留 `viewBox`、预览色（`#D6A24A`/`#8A97A3`）→ `currentColor`。
- 只改 `.svg` 母版，跑一次 `node assets/ui/build-icons.mjs`，两边一起更新，**不可能再漂移**。
- `icons.svg` 由 `icons.js` 整份导出，不再手抄。

### 2.3 CSS 收尾

- 删掉 `.abtn.primary` 的矩形底色（改由 SVG 承载主/次差异）。
- 导航序号从「右下角 7px 小字」挪到新画的序号牌里（`left:50%` 居中）。
- 部门徽记统一：`img.em` 16px + 同款 1px 边框 + 内缩 1px，与文字徽章同高同框。

## 4. 没做 / 建议下一步

1. **主题变量（建议优先）**：给控件引入 `--hl`（高光）/`--sh`（投影），白主题换成暖褐投影。需要 `build-icons.mjs` 把 `#fff`/`#000` 转成 `var(--hl,#fff)`/`var(--sh,#000)`，改动集中在一个函数里。
2. **部门徽记统一重绘**：18px 下可读的单色徽章（站点/逆模因/超形上/数学/时间/误传/档案/采购/炼金/伦理），比现在的彩图缩略图清楚得多；顺便把 12 张未用图移出仓库（-941 KB）。
3. **卡片（`frame-card`）**：仍是 1px 细线 + 三个穿孔点，和加粗后的按钮不同材质；建议同一套边光处理，但降一档（卡片不该像按钮）。
4. **`assets/README.md` 授权段落**：按"官方徽记 + CC BY-SA 署名"改写，删掉"不含任何官方图片"这句。
