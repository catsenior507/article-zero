## 0. 三十秒版本

**现在是什么**：一个 SCP 主题大战略游戏的 **1920×1080 静态原型**——纯 HTML/CSS/JS，无框架、无构建、无包管理。

> 2026-11-20 更新：已接入时间引擎与测试控制台（`13-时间与事件.md`），时间与事件有状态了；资源数字仍是静态。

**你要做的**：把写死的数字换成真实数据，接上回合推进与存读档。

**你不要动的**：`mockups/v2.css`、`assets/ui/*.svg`、`assets/map/build-world.py`，
以及任何标着「生成物 / 勿手改」的文件（见 §5）。视觉层的问题找我，别改 CSS 绕过。

## 2. 怎么跑

```
直接双击 mockups/01-main.html     # file:// 即可，无依赖、无服务器
```

**关键限制：`file://` 下不能 `fetch()` 本地 JSON**（CORS 拦截）。
所以数据接入有两条路，二选一：

- **A（推荐，改动最小）**：把状态内联成 `mockups/state.js`（`window.STATE = {...}`），
  和 `ui.js` 一样用 `<script src>` 引；后端只要能生成这个文件即可。
- **B**：起一个本地静态服务器（`python -m http.server`），改成 `fetch('state.json')`。
  但这会破坏"双击就能看"的便利，评审时容易出事。

**画布**：设计稿固定 1920×1080，由 JS 算 `--s = min(内宽/1920, 内高/1080)` 整体缩放居中。
你给的所有坐标都在这套 1920×1080 的坐标系里。

## 3. 数据契约（核心）

下面是**我写死在页面里的全部数据**，也就是你要提供给 UI 的字段。字段名是我临时起的，你可以改，
但改完要同步改 HTML（见 §7 的接入建议）。

### 3.1 顶部资源条（9 个数字，分三簇）

```js
{
  material: { funding: {v: "$120", delta: "+10", dir: "up"},
              staff:   {v: 84, max: 100},
              morale:  {v: 65, dim: true} },          // dim = 默认虚化，悬停展开
  anomaly:  { capacity:{v: 28, max: 40},
              contam:  {v: "08", delta: "+2", dir: "up", neg: true},
              asset:   {v: "06", dim: true} },
  politics: { veil: 78, authority: 60, consensus: 55 },
  date: { year: 2049, month: 3, term: "23 / 54", level: "LEVEL 5" }
}
```

格式约定（**属于设计，不是随手写**）：
- 小于 10 的值补零：`08`、`06`、`04`；
- 涨跌用 `▲` / `▼` 加符号；污染上涨是负面的，加 `.neg`（红色）；
- 有上限的值写成 `28/40`，上限是 `.s`（灰、小一号）；
- 数字一律等宽（Consolas），不要换成比例字体。

### 3.2 预警横条

```js

    level: "K", code: "XK-17", name: "人口普查", tag: "S2 显形",
    scp: "SCP-8███", progress: 0.55, progressText: "55 / 100",
    countdown: 12,                       // 距不可逆；未立案时为 null，条上不显示时钟
```

只有一条 K 级预警的位置。多条时要么轮播、要么显示 `+1`——**这是产品决策，你定，告诉我怎么表现**。

事件门的标点语义（**已实现，别改**）：

| 状态 | 类名 | 含义 |
|---|---|---|
| 红点 + 脉冲 | `.dot.unread` | 有新事件，玩家还没看 |

## 5. 资产与生成链（**改素材必须走这条路**）

```bash
# 控件：assets/ui/*.svg（母版）→ icons.js + icons.svg
node assets/ui/build-icons.mjs

# 地图：assets/map/data/*.geojson → world-dots.png + world-data.js
python assets/map/build-world.py
```

- 依赖：**Node**（无 npm 包）；**Python 3 + Pillow + scipy**（scipy 只用于"最近区域"距离场）。
- `build-world.py` 会自己打印**覆盖率**和空白分布，改完看输出就知道有没有漏洞。
- 母版里写的是预览色（琥珀 `#D6A24A` / 钢灰 `#8A97A3`），构建时自动换成 `currentColor`；
  `#fff`/`#000` 是写死的高光与投影。
- **许可**：地图数据是 Natural Earth（公有领域）；`assets/scp/*.png` 是官方部门徽记（CC BY-SA，
  逐张记录在 `ATTRIBUTION.md`）。发布前必须处理署名与商标，别默认"都是原创"。

## 6. 已知坑（我踩过，都会让你难受）

### 6.1 沙箱写权限
这台机器上，**shell 进程写不进 `assets/`、`docs/`、`mockups/` 三个子目录**（只有工作区根目录拿到了授权，
工作区根目录本身还被修过一次 ACL）。所以你：
- 跑生成脚本（往 `assets/` 写）会 `AccessDenied` ——那是权限，不是代码 bug；
- 编辑文件用编辑工具，别用 `Set-Content` / `>` 重定向；
- 需要批量生成时，第一次会弹一次授权，接受即可。

### 6.2 `file://` 不能 `fetch`
见 §2。这是最容易在评审前一晚炸的坑。

### 6.3 坐标是绑死的
pin 是像素、heat 是像素、掩膜依赖 `world-data.js` 的多边形。**改投影 = 全部重来**。

### 6.4 白主题有个未修的材质问题
控件里的高光/投影写死成 `#fff`/`#000`，换到米色纸面主题上，深色内凹会变成"墨块"。
我留了方案（引入 `--hl`/`--sh` 两个变量），没做。**别自己调 CSS 数值，找我对齐。**

### 6.5 生成物别手改
`icons.svg`、`world-data.js`、`world-dots.png` 都是脚本产物。手改会在下次构建时消失，
而且不会有任何提示。

### 6.6 没有的东西
没有测试、没有 lint、没有构建、没有 i18n、没有 a11y（`aria-label` 只在设计文档里写了，代码里没实现）。
按钮文案含大量 `████` 遮蔽号、`SCP-8███`——**它们是文案，不是占位符**。

### 6.7 字号下限
7–8px 的字（deck code、序号）在 1920 下实际读不出来。要加信息，先问我能不能塞得下。

## 7. 建议的接入顺序

1. **先别接后端。** 把 §3 的形状抽成 `mockups/state.js` 里的一个对象，写一个 `render(state)`
   （原生 JS，20~40 行足够）把 `textContent` 换掉。这样你在没有服务器的情况下就能验证所有界面。
2. 把 `ui.js` 里的 `flash(...)` 换成 `emit('door:open', {id})` 之类的事件，由你写一个 controller 消费。
3. 接回合：`tick()` → 事件倒计时减一、资源结算、K 级进度推进 → 重新 `render()`。
4. 接存档：状态对象就是存档，`JSON.stringify` 即可；注意保留事件的 `unread` 与 `read` 时间戳。
5. 真要引框架（React/Vue）之前先跟我说——那等于重做视觉层，成本比你想的大。

**替换点位**（现在都是写死的文本，建议改成 `data-bind` 占位）：

```html
<span class="v" data-bind="material.funding.v">$120</span>
```

```js
document.querySelectorAll('[data-bind]').forEach(el => {
  const v = el.dataset.bind.split('.').reduce((o,k) => o?.[k], state);
  if (v != null) el.textContent = v;
});
```
