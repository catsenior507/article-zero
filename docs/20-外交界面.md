# 20 · 外交界面

> 向区域政府要钱、要地、要沉默。**所有政体均为虚构**，避免指向现实国家。

---

## 0. 为什么用虚构名字

现实国家名会带来两个问题：把现实政治立场绑进游戏，以及潜在的名誉/商标风险。所以七个区域各配一个**虚构政体**，只保留"区域 + 预算 + 条件"的结构：

| 区域 | 政体 | 代号 | 年度预算 | 附加条件 |
|---|---|---|---|---|
| 北美 | 阿卡迪亚合众国 | AC | $38M | 驻站权 |
| 欧洲 | 欧罗巴共同体 | EC | $30M | 研究共享 |
| 亚洲 | 东亚联合体 | EA | $26M | 沉默条款 |
| 南美 | 南十字星联盟 | SC | $14M | 不干涉 |
| 非洲 | 赤道非洲共同体 | EQ | $9M | 基础设施 |
| 大洋洲 | 珊瑚海公约 | CS | $12M | 海域通行 |
| 南极 | 极地研究理事会 | PR | $2M | 科考配额 |

名字是"地理 + 政体类型"的组合，不指向任何现实国家；旗帜、语言、领导人一概不出现。

## 1. 四个动作

| 动作 | 得到 | 付出 | 冷却 |
|---|---|---|---|
| **请求拨款** | 一次性拨款 | 关系 −3 | 6 个月 |
| **谈判** | 关系 +6 | $2M 游说费 | 3 个月 |
| **施压** | 拨款的 75% | 关系 −12、帷幕 −1 | 12 个月 |
| **交换** | 拨款的 125% | 关系 +2，记下一次让步 | 9 个月 |

拨款公式：

```
grant = budget × (0.35 + relation/200) × (1 + leverage)
```

以阿卡迪亚为例：38 × (0.35 + 0.31) × 1.55 ≈ **$38.9M**；施压约 $29.2M。

规则：

- 关系 < 25 时请求被拒（关系再 −2）；
- 关系上限 95，下限 0；
- 冷却按游戏日计算（1 个月 = 30 天），与时间轴共用 `GameAPI.state().day`。

## 2. 关系与态度

| 区间 | 态度 | 含义 |
|---|---|---|
| < 20 | 敌对 | 拒绝一切请求，可能倒向反基金会势力 |
| 20–39 | 冷淡 | 只接受谈判 |
| 40–59 | 务实 | 正常拨款 |
| 60–79 | 合作 | 拨款上浮，可谈交换 |
| ≥ 80 | 盟友 | 可解锁联合行动（待做） |

关系不是静态的：`docs/17` 的区域社会张力会作为每月的关系漂移项（内乱、政权更迭、丑闻），M11.4 接。

---

## 3. 与财政的关系

外交拨款是财政的**第四条收入腿**：不占年度预算、一次性、可谈判。

- 在 `docs/14` 的三条腿之外，它提供"应急现金"；
- 施压拿钱最快，但会掉帷幕——与"异常变现"是同一类诱惑；
- 交换拿到更多钱，但记下的让步会在后续事件里被追讨（驻站权、研究共享、沉默条款）。

M11.5 会把"国家拨款"从静态公式改成"由七个政体的关系汇总"，这样外交操作直接影响月度收入。

## 4. 存档结构

```js
world: {
  governments: [
    { id: 'na', relation: 62, cooldownDay: 0, concessions: [] },
    { id: 'eu', relation: 48, cooldownDay: 0, concessions: [] },
    ...
  ]
}
```

- 名称、预算、条件在 `mockups/diplomacy.js` 的 `GOV_DEFS` 里（改文案不用动存档）；
- 关系、冷却、让步在存档里（会随游戏变化）；
- 冷却存的是**绝对天数**，不是剩余月数，读档后仍然正确。

## 5. 界面

右侧面板（520×604，`top:168`，避开时间轴）：

- 列表：代号、名称、关系条、数值；
- 详情：名称 + 区域、关系、年度预算、态度、条件（已让步会标注）；
- 四个动作按钮，冷却中禁用；
- 提示行显示"可请求 $X；施压 $Y（关系 −12）"；
- 日志：最近 8 条操作。

打开方式：右侧导航的「外交」按钮、底栏「外交 / GoI」门，或 `?diplomacy=1`。
