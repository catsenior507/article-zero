# 16 · 区域经济与黄金储备

> 统一大账户只解决了"总数"，没解决"位置"。同样一笔钱，在瑞士和在南苏丹能买到的东西差三倍；同一个金库，在北美是资产，在战乱区是别人眼里的军费。
> 本文把**物价表与金价做成存档内的数据**，不是代码里的常量。

---

## 0. 一句话

**主账户是账，站点金库是底牌；区域物价决定你每个月被地理收多少税。**

---

## 1. 为什么统一账户不够

| 漏洞 | 表现 |
|---|---|
| **可冻结** | 审计、制裁、金融危机时主账户可能被冻结 1–3 回合，此时只有金库能动 |
| **可追溯** | 主账户每一笔都有流水，黑账要洗；黄金没有流水 |
| **不落地** | 主账户不区分地点，但站点在本地雇人、买电、修设备，价格随地区变 |

所以：主账户负责"合法的大钱"，站点金库负责"不能等的钱"，区域表负责"同样的钱在各地值多少"。

## 2. 黄金储备

### 2.1 单位与定价

- 单位：**千克**（存档里存 kg，显示时换算盎司）；
- 1 kg = **32.1507 troy oz**；
- 金价存在存档里：`market.goldUsdPerOz`，开局 **$3,587.20**（2026-11-20 收盘，[Trading Economics](https://tradingeconomics.com/commodity/gold)）；
- 站点金库估值 = `kg × 32.1507 × 金价 × (1 − 本地价差)`。

> 2026 年金价从 1 月的 $5,608 跌到 11 月的 $3,587，年内振幅 36%。这个波动本身就是机制：金库不是稳定的储备，是**会缩水的底牌**。

### 2.2 开局分布

19 个站点里只有 3 个保留实体金库（老站点，不信任银行）：

| 站点 | 区域 | 黄金 | 估值（$3,587/oz） |
|---|---|---|---|
| S-87 | 北美 | 30 kg | $3.46M |
| S-19 | 南美 | 20 kg | $2.31M |
| S-106 | 非洲 | 15 kg | $1.73M |
| 合计 | | **65 kg** | **$7.50M** |

对比主账户 $120M——金库只有 6%，它是"最后一笔钱"，不是主要资产。

### 2.3 四种用途

| 用途 | 规则 | 代价 |
|---|---|---|
| **变现** | 按当日金价 ×(1−价差) 卖给本地渠道，**延迟 1 回合到账** | 价差 1–6%（看区域），大额再折 2% |
| **黑付** | 直接支付隐秘行动，不走账 | 运输与交割风险；单次上限 5 kg |
| **抵押** | 向本地势力/银行借款，上限为估值的 70% | 利息 3%/回合；违约则金库被接管 |
| **应急** | 主账户冻结时，金库仍可支付本地开销 | 只能付该站点所在区域的开销 |

### 2.4 风险

| 风险 | 触发 | 后果 |
|---|---|---|
| **价格** | 月度随机游走 ±3%，事件可 ±15% | 估值波动；抵押率被动变化 |
| **运输** | 跨区转移黄金 | 每 10 kg 有 8% 概率丢失/被劫 |
| **没收** | 区域 `stability < 0.5` 且发生政变/战乱 | 该站点金库全部损失 |
| **账实不符** | 站点腐败或内部盗窃 | 审计时发现，权威 −5，追回率 50% |

### 2.5 与审计的关系

黄金**不进审计的黑账判定**，但进**盘点**：每个站点每年盘点一次，账实不符会触发一次内部调查。
这正是黄金的两面：它躲得过财务审计，躲不过物理盘点。

## 3. 区域物价表

### 3.1 七个区域

沿用地图的七大洲：`na` 北美 / `sa` 南美 / `eu` 欧洲 / `af` 非洲 / `as` 亚洲 / `oc` 大洋洲 / `an` 南极。

每个区域是一组**相对北美的系数**（北美 = 1.00），外加风险字段：

| 字段 | 含义 | 影响 |
|---|---|---|
| `labor` | 人工成本 | 站点人事、行动人力 |
| `construction` | 建设与维护 | 设施维护、新建站点 |
| `energy` | 工业电价 | 站点电力 |
| `media` | 媒体/法律/公关 | 帷幕维护 |
| `security` | 安保合同价 | 行动待命、站点警卫 |
| `corruption` | 0–1，腐败与抽成 | 所有本地支出的漏损，黑账更便宜 |
| `stability` | 0–1，社会稳定 | 金库被没收、站点停摆的概率 |
| `fxVol` | 汇率月波动 | 本地货币支出换算的噪声 |
| `goldSpread` | 本地金价差 | 变现折价 |

### 3.2 基准值（2026-11）

| 区域 | labor | constr | energy | media | security | corr | stability | fxVol | goldSpread |
|---|---|---|---|---|---|---|---|---|---|
| 北美 na | 1.00 | 1.00 | 1.00 | 1.00 | 1.00 | 0.05 | 0.95 | 0.00 | 1% |
| 欧洲 eu | 1.08 | 1.24 | 2.00 | 1.10 | 1.05 | 0.08 | 0.93 | 0.01 | 2% |
| 亚洲 as | 0.45 | 0.55 | 0.90 | 0.55 | 0.45 | 0.22 | 0.75 | 0.02 | 3% |
| 南美 sa | 0.35 | 0.50 | 0.80 | 0.40 | 0.38 | 0.28 | 0.65 | 0.04 | 5% |
| 非洲 af | 0.20 | 0.45 | 0.90 | 0.30 | 0.25 | 0.35 | 0.55 | 0.05 | 6% |
| 大洋洲 oc | 0.95 | 1.10 | 1.20 | 0.90 | 0.95 | 0.05 | 0.90 | 0.01 | 3% |
| 南极 an | 2.50 | 3.00 | 4.00 | 0.00 | 2.00 | 0.00 | 0.40 | 0.00 | 10% |

依据：

- `labor`：制造业全成本人工，美国 $50.8/h、德国 $55/h、中国 $6.7/h（[Intratec 2025](https://newsroom.intratec.us/press-releases/germany-manufacturing-labor-55-an-hour/)），其余按 Numbeo 生活成本指数插值（[Numbeo 2026 年中](https://www.numbeo.com/cost-of-living/rankings_by_country.jsp?title=2026-mid&displayColumn=0)）；
- `construction`：德国建厂成本为美国的 1.24×（Intratec），其余按区域建筑成本与物流推估；
- `energy`：美国工业电价 8.51¢/kWh（[EIA 2025](https://www.eia.gov/electricity/annual/html/epa_02_07.html)），欧洲约为其 2×，南极按柴油发电 4×；
- `corruption` / `stability`：按透明国际与冲突风险的主观映射，属于设计取值；
- `goldSpread`：本地金市买卖价差，战乱区更宽。

### 3.3 成本公式

每个站点的月支出不再是一个常数，而是：

```
站点人事 = 0.9M × 区域.labor × (1 + corruption × 0.2)
站点设施 = 1.4M × (0.6 × 区域.constr + 0.4 × 区域.energy)
站点帷幕 = 0.35M × 区域.media × (1 + corruption)
```

行动按发起区域计费：

```
出动成本 = 基础 4.0M × (0.5 × labor + 0.5 × security) × (1 + corruption)
```

> 北美出动仍是 $4.0M；非洲出动约 $1.6M，但腐败漏损与善后风险更高。

### 3.4 动态变动

**这张表不是常量，是存档里的数据**，三种方式变化：

1. **月度漂移**：每个系数每月 `±1.5%` 随机游走，`fxVol` 高的区域漂移更大；
2. **事件改写**：财政/经济事件直接改表，例如
   - 货币危机：`labor ×0.85, fxVol +0.03, stability −0.05`
   - 战时状态：`construction +50%, stability −0.2, media +30%`
   - 制裁：主账户冻结 2 回合，`goldSpread +2%`
   - 经济繁荣：`labor +8%, media +5%`（本地成本上升）
3. **版本快照**：每月保存一份 `economySnapshot`，报表里可回看"这个月为什么贵了"。

## 4. 存档结构

```js
world: {
  economyVersion: 1,
  market: {
    goldUsdPerOz: 3587.20,
    updated: '2026-11-20'
  },
  regions: {
    na: { labor: 1.00, construction: 1.00, energy: 1.00, media: 1.00,
          security: 1.00, corruption: 0.05, stability: 0.95,
          fxVol: 0.00, goldSpread: 0.01 },
    eu: { ... }, as: { ... }, sa: { ... }, af: { ... }, oc: { ... }, an: { ... }
  },
  sites: [
    { id: 'S-87',  region: 'na', goldKg: 30, staff: 120, status: 'normal' },
    { id: 'S-19',  region: 'sa', goldKg: 20, staff: 90,  status: 'normal' },
    { id: 'S-106', region: 'af', goldKg: 15, staff: 80,  status: 'normal' }
    // 其余 16 个站点 goldKg = 0
  ],
  economySnapshot: { /* 上个月的 regions 副本，用于报表对比 */ }
}
```

规则：

- 所有乘法系数从 `regions` 读，**代码里不出现任何地区常量**；
- 站点必须属于一个区域；区域表新增字段时，旧存档用默认值补；
- `economyVersion` 用于迁移；`market.updated` 用于判断金价是否过期（超过 30 天按漂移补算）。

## 5. 一个月的账单（示例）

19 个站点分布：北美 4 / 欧洲 4 / 亚洲 5 / 南美 2 / 非洲 2 / 大洋洲 1 / 南极 1。

| 科目 | 算法 | 月额 |
|---|---|---|
| 站点人事 | Σ 0.9M × labor | $13.6M |
| 总部人事 | 北美基准 | $3.2M |
| 站点设施 | Σ 1.4M × (0.6 constr + 0.4 energy) | $28.9M |
| 帷幕 | 站点 0.35M × media（$4.7M）+ 总部媒体（$5.4M） | $10.1M |
| 行动待命 | 北美 + 欧洲为主 | $6.0M |
| 科研 | 10 部门 | $22.0M |
| 杂项 | — | $4.0M |
| **合计** | | **$87.8M** |

与 `docs/15` 的 $90.2M 差 2.7%——区域化让**便宜地区的站点更便宜、贵地区的站点更贵**，总量变化不大，但结构变了：玩家会开始问"为什么南极那个站一个月要 $4M"。

## 6. UI

- **财政面板新增两页**：`站点` 与 `金库`；
- **站点页**：19 行，每行显示区域、月支出、金库、状态；点开看成本拆解；
- **金库页**：总 kg、估值、金价走势、每站分布；变现/转移/抵押三个动作；
- **区域页**：7 行系数表，带月度变化箭头；事件改表时在这里高亮。

## 7. 与其它系统的耦合

| 系统 | 耦合 |
|---|---|
| 帷幕 | 区域 `media` 决定同样一笔封口费在各地能买多少版面 |
| K 级 | 站点被攻破时，该站金库可能被抢；`stability` 低的区域概率更高 |
| 审计 | 黄金不进流水，但每年盘点；账实不符触发调查 |
| 制裁/冻结 | 主账户冻结时，金库是唯一可动用的钱 |
| 黄金价格 | 月度游走 + 事件；金价暴跌会让抵押率跌破警戒线 |

## 8. 待确认

1. **金价基准**用 2026-11-20 的 $3,587，还是设一个更"长期"的均值（如 $4,200）？
2. **黄金初始占比**：现在 65 kg ≈ $7.5M（主账户的 6%），要不要提高到 15%？
3. **区域数量**：7 个大洲是否太粗？亚洲内部差异极大（中国 vs 日本差 8 倍），要不要拆成"东亚/南亚/中东"？
4. **动态漂移幅度**：每月 ±1.5% 是否合适？会不会让玩家觉得"账不可预测"？
5. **金库被抢**：K 级事件里要不要明确写"可被抢"，还是只作为隐性风险？
