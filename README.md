## 三句话

1. 你不是在收容异常，你是在决定这个组织**用什么姿势**继续存在。
2. 意识形态不是善恶条，是**你手里能用的解法集合**——选了什么，就等于放弃了另外几种活法。
3. 每局随机 1–3 条 K 级情景链。征兆先到，解释后到，账单最后到。

## 这不是什么

| 不是 | 因为 |
|---|---|
| SCP 主题的《监狱建筑师》 | 收容不是生产，是负债。每多收一个，牌库就危险一分。 |
| 道德选择游戏 | 四根轴不是善恶条，是**制度形态**。没有"好人路线"。 |
| Jump scare 合集 | 恐怖来自公文、编号、和你自己签的字。 |
| 需要背 wiki 才能玩 | 所有设定在游戏内自洽可学；wiki 知识只是彩蛋。 |
| 一款"关于 SCP 的游戏" | 它是一款**关于记录、署名与删除**的游戏，恰好发生在基金会里。 |

## 一句话工作流

```
纸面原型(18回合) → 可玩循环(1链/4部门) → 垂直切片(54回合/3链/42卡)
   → 元叙事层(存档/信标/觉醒) → 平衡与打磨 → 发布 + SCP条目
```

## 任务树（多 agent 协同）

`tasks.json` 是整个项目的开发任务树：9 个阶段、44 个节点、35 个可领取任务，每个任务带 `owner / status / prio / deps / deliverable / accept`。

```bash
node tools/tasks-check.mjs
```

会校验 id、状态、依赖与循环，并列出**当前可并行领取**的任务和**等待依赖**的任务。领取规则：`status` 改 `doing`、填 `owner`；完成后改 `done`，下游节点自动进入可领取列表。
