# UI 控件素材（先画，再用）

这里放**按钮与控件的独立矢量稿**。每个文件都是可直接打开查看的 SVG，画好之后再进入 sprite 供界面使用。

> **母版是唯一真源。** 改完这里的 `.svg`，跑一次 `node assets/ui/build-icons.mjs`，
> 它会重建 `assets/icons.js` 里的 `frame-*`，并整份导出 `assets/icons.svg`。不要再手改那两个文件。

## 按钮解剖（v12：四段式）

v11 之前是"堆 8 层"，但铆钉 1.4px、刻线 0.3px，1× 下全部消失，读起来只是描边框。
v12 改成四段，每段都要求**在 1× 下看得见**：

1. **边光**（关键）：
   - 色晕：同一路径再描一遍，`stroke-width` 2.4–3.6，主题色 42–46% 透明；
   - 金属边：再描一遍，`stroke-width` 1.1–1.9，描边用 `linear-gradient`：顶部白 → 中部黑 → 底部更黑。
   - 一条渐变描边就能把平面变成有厚度的金属边，这是本轮最有效的一招。
2. **内凹**：顶部深、底部回弹光的凹面；八角控件用**八角**内凹，不要用 `rect`（方角会和轮廓打架）。
3. **五金**：带槽螺钉（暗底 + 亮圈 + 斜槽）、对接槽、冲孔、铆钉——**最小 1.7px**，再小就看不见。
4. **状态件**：LED（辉光 + 灯芯 + 高光点）、序号牌、状态条。

统一规则：顶光来自正上方；外板亮、内面暗；每个转角有五金件；主按钮用主题色且多一条左状态条，次按钮降饱和。

## 工作流

```bash
# 1. 改母版形状
# 2. 生成 sprite（两条产物一起更新）
node assets/ui/build-icons.mjs
# 3. 刷新页面
```

颜色约定：

- 母版里写的是**预览色**（琥珀 `#D6A24A` / 钢灰 `#8A97A3`），只为能在文件里看清；
- 生成时预览色统一替换为 `currentColor`，运行时由主题变量决定；
- `#fff` / `#000` 是写死的高光与投影（暂未接主题，见 `docs/10-素材审查.md` §1.5）。
