## 画法

1. **剪影优先**：先保证 28px 下轮廓能区分（肩线、发型、配件），再画五官；
2. **三个明度**：主体 `#A9B4BF`、结构线 `#E3E9EE`（低透明）、识别物 `#D6A24A`；
3. **一人一件**：每个角色只有一处强调色，用于快速辨认；
4. **五官用挖空**：眼、嘴在 mask 里挖掉，露出背景，深色/浅色主题都不会糊；
5. **透明底**：不画背景与边框，由卡片提供。
